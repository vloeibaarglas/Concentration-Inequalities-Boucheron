**Central idea.** (Angluin–Valiant.) Direct Chernoff bounds using $1-p_i+p_ie^{\pm\lambda} \leq \exp(p_i(e^{\pm\lambda}-1))$. The upper tail optimizes to $\exp(-np\cdot h(\varepsilon/p))$ with $h(\delta) = (1+\delta)\log(1+\delta)-\delta$, and Exercise 2.8(b) gives $h(\delta) \geq \delta^2/(2(1+\delta/3)) \geq \varepsilon^2/3$ after using $p \leq 1$, $\varepsilon \leq 1-p$. The lower tail similarly gives $\exp(-np\cdot k(\varepsilon/p))$ with $k(\delta) = \delta+(1-\delta)\log(1-\delta) \geq \delta^2/2$, and $p \leq 1$ converts $n\varepsilon^2/(2p)$ to the claimed $np\varepsilon^2/2$.

**Solution.** Let $\varepsilon > 0$. If $p = 0$, then $S_n = 0$ a.s. and both probabilities are $0$. Assume $p > 0$.

*Upper tail.* If $\varepsilon > 1-p$, then $np + n\varepsilon > n \geq S_n$, so $\mathbb{P}\{S_n - np \geq n\varepsilon\} = 0$. Assume $0 < \varepsilon \leq 1-p$. For $\lambda > 0$, $\mathbb{E}e^{\lambda X_i} = 1-p_i+p_ie^{\lambda} \leq \exp(p_i(e^{\lambda}-1))$ (using $1+x \leq e^x$). By independence and Chernoff,
\begin{align*}
\mathbb{P}\{S_n - np \geq n\varepsilon\} &\leq e^{-\lambda n\varepsilon}\,\mathbb{E}e^{\lambda(S_n-np)} \\
&\leq \exp\!\big(np(e^{\lambda}-1) - \lambda np - \lambda n\varepsilon\big).
\end{align*}
Minimizing $\phi(\lambda) = np\big[e^{\lambda}-1-\lambda(1+\varepsilon/p)\big]$: $\phi'(\lambda) = 0$ gives $e^{\lambda} = 1+\varepsilon/p$, i.e., $\lambda = \log(1+\delta)$ with $\delta = \varepsilon/p > 0$; since $\phi'' > 0$ this is the minimizer, yielding
$$\mathbb{P}\{S_n - np \geq n\varepsilon\} \leq \exp\!\big(-np\cdot h(\delta)\big), \quad h(\delta) = (1+\delta)\log(1+\delta)-\delta.$$
By Exercise 2.8(b), $h(\delta) \geq \frac{\delta^2}{2(1+\delta/3)}$. Hence
$$h(\varepsilon/p) \geq \frac{(\varepsilon/p)^2}{2(1+\varepsilon/(3p))} = \frac{\varepsilon^2}{2p^2+2p\varepsilon/3} \geq \frac{\varepsilon^2}{3},$$
because $2p^2 + 2p\varepsilon/3 \leq 2 + 2/3 = 8/3 < 3$ (using $0 < p \leq 1$, $0 < \varepsilon \leq 1$). Therefore $\mathbb{P}\{S_n - np \geq n\varepsilon\} \leq e^{-np\varepsilon^2/3}$.

*Lower tail.* For $\lambda > 0$, $\mathbb{E}e^{-\lambda X_i} = 1-p_i+p_ie^{-\lambda} \leq \exp(p_i(e^{-\lambda}-1))$, so
$$\mathbb{P}\{S_n - np \leq -n\varepsilon\} \leq \exp\!\big(np(e^{-\lambda}-1) + \lambda np - \lambda n\varepsilon\big).$$
Maximizing $g(\lambda) = -(e^{-\lambda}-1+\lambda) + \lambda\delta$ (with $\delta = \varepsilon/p$): $g'(\lambda) = e^{-\lambda}-(1-\delta) = 0$ gives $\lambda = -\log(1-\delta)$, valid for $\delta \in (0,1)$, i.e., $0 < \varepsilon < p$; $g'' < 0$ confirms a maximum, with value $g(-\log(1-\delta)) = \delta + (1-\delta)\log(1-\delta) =: k(\delta)$. Thus, for $0 < \varepsilon < p$,
$$\mathbb{P}\{S_n - np \leq -n\varepsilon\} \leq \exp\!\big(-np\cdot k(\varepsilon/p)\big).$$
Now $k(\delta) \geq \delta^2/2$ on $(0,1)$: with $\phi(\delta) = k(\delta) - \delta^2/2$, $\phi(0) = 0$ and $\phi'(\delta) = -\log(1-\delta) - \delta \geq 0$. So
$$\exp\!\big(-np\,k(\varepsilon/p)\big) \leq \exp\!\left(-\frac{n\varepsilon^2}{2p}\right) \leq \exp\!\left(-\frac{np\varepsilon^2}{2}\right),$$
using $1/(2p) \geq p/2 \iff p^2 \leq 1$.

If $p \leq \varepsilon \leq 1$: then $\{S_n - np \leq -n\varepsilon\} \subseteq \{S_n = 0\}$, and $\mathbb{P}\{S_n = 0\} = \prod_i(1-p_i) \leq e^{-\sum_i p_i} = e^{-np} \leq e^{-np\varepsilon^2/2}$ since $\varepsilon^2 \leq 1 < 2$. If $\varepsilon > 1$, the event is empty. This completes the lower tail.

*Remark.* The intermediate bounds $\exp(-np\cdot h(\varepsilon/p))$ and $\exp(-np\cdot k(\varepsilon/p))$ give the sharper multiplicative form (with $\delta = \varepsilon$ for $S_n \ge (1+\varepsilon)np$). The same proof works for $[0,1]$-valued $X_i$: the mgf bound $\mathbb{E}e^{\lambda X_i} \le 1-p_i+p_ie^\lambda$ becomes an inequality by convexity of $x \mapsto e^{\lambda x}$.
