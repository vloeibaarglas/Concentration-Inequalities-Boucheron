**Central idea.** The Chernoff bound $\mathbb{P}\{B \geq an\} \leq \inf_{\lambda>0}[(1-p+pe^\lambda)e^{-\lambda a}]^n$, optimized explicitly: the minimizer $e^\lambda = a(1-p)/(p(1-a))$ yields the KL-divergence (method-of-types) form. The cruder $e^{a-p}$ bound follows from $\log(1+z) \leq z$. The lower tail is the same argument with $\lambda < 0$.

**Solution.** Let $B \sim \mathrm{Binomial}(n,p)$ and $p \leq a < 1$. If $p = 0$, then $B = 0$ a.s. and $\mathbb{P}\{B > an\} = 0$; if $a = p$, the first bound equals $1$. Assume $0 < p \leq a < 1$ (the case $p < a$ below; $a=p$ is trivial).

For $\lambda > 0$, by Markov's inequality, $\mathbb{P}\{B \geq an\} \leq \mathbb{E}[e^{\lambda B}]/e^{\lambda an} = [(1-p+pe^\lambda)e^{-\lambda a}]^n$ (the same proof works for $\geq$, hence for $>$). Minimize $f(\lambda) = \log(1-p+pe^\lambda) - \lambda a$:
$$f'(\lambda) = \frac{pe^\lambda}{1-p+pe^\lambda} - a = 0 \iff pe^\lambda(1-a) = a(1-p) \iff e^\lambda = \frac{a(1-p)}{p(1-a)} > 1,$$
valid since $a > p$. Since $f'' > 0$, this is the minimizer. Substituting,
$$1-p+pe^{\lambda^*} = 1-p+\frac{a(1-p)}{1-a} = \frac{1-p}{1-a}, \qquad e^{\lambda^* a} = \left(\frac{a(1-p)}{p(1-a)}\right)^a,$$
so with $D(a\|p) = a\log\frac{a}{p} + (1-a)\log\frac{1-a}{1-p}$,
$$\mathbb{P}\{B > an\} \leq \mathbb{P}\{B \geq an\} \leq \left[\left(\frac{p}{a}\right)^a\left(\frac{1-p}{1-a}\right)^{1-a}\right]^n = e^{-nD(a\|p)}.$$
For the second inequality, $(1-a)\log\frac{1-p}{1-a} \leq a-p$: indeed $\psi(a) = a-p-(1-a)\log\frac{1-p}{1-a}$ satisfies $\psi(p) = 0$ and $\psi'(a) = \log\frac{1-p}{1-a}$, so $\psi$ decreases on $(0,p]$ and increases on $[p,1)$, giving $\psi \geq 0$. Exponentiating yields $\left(\frac{1-p}{1-a}\right)^{1-a} \leq e^{a-p}$, hence
$$\mathbb{P}\{B > an\} \leq \left[\left(\frac{p}{a}\right)^a e^{a-p}\right]^n.$$

For $0 < a < p$ (if $p = 1$, then $B = n$ a.s. and $\mathbb{P}\{B \leq an\} = 0$; assume $p < 1$), use $\lambda = -\mu < 0$: $\mathbb{P}\{B \leq an\} \leq [(1-p+pe^{-\mu})e^{\mu a}]^n$. Minimizing $g(\mu) = \log(1-p+pe^{-\mu}) + \mu a$ gives $e^{\mu^*} = p(1-a)/(a(1-p)) > 1$ (since $p > a$), and the same algebra yields $\mathbb{P}\{B \leq an\} \leq [(p/a)^a((1-p)/(1-a))^{1-a}]^n$. The bound $((1-p)/(1-a))^{1-a} \leq e^{a-p}$ holds for $a < p$ as well since $\psi(a) > \psi(p) = 0$ there.
