**Central idea.** $\{\sqrt{B}-\sqrt{np} \geq \varepsilon\sqrt{n}\} = \{B \geq n(\sqrt{p}+\varepsilon)^2\}$ reduces each tail to a binomial deviation at $a = (\sqrt{p}\pm\varepsilon)^2$, controlled by the KL Chernoff bound of Exercise 2.11. The analytic core is $D((\sqrt{p}+\varepsilon)^2\|p) > 2\varepsilon^2$ (upper) and $D((\sqrt{p}-\varepsilon)^2\|p) > \varepsilon^2$ (lower), proved from $\ln(1+x) \geq \frac{2x}{2+x}$ ($x>0$) and $\ln(1-y) \geq \frac{-y}{1-y}$ ($0 \leq y < 1$).

**Solution.** Let $\varepsilon > 0$, $u = \sqrt{p} \in [0,1]$, $B \sim \mathrm{Binomial}(n,p)$. Write $D(a\|p) = a\ln\frac{a}{p} + (1-a)\ln\frac{1-a}{1-p}$. Exercise 2.11 gives $\mathbb{P}\{B \geq na\} \leq e^{-nD(a\|p)}$ (its Chernoff proof works for $\geq$) and $\mathbb{P}\{B \leq na\} \leq e^{-nD(a\|p)}$.

*Upper tail.* $\{\sqrt{B}-\sqrt{np} \geq \varepsilon\sqrt{n}\} = \{B \geq n(u+\varepsilon)^2\}$. If $u = 0$ or $u+\varepsilon > 1$, this probability is $0$. Assume $0 < u < 1$ and $u+\varepsilon \leq 1$, and set $a = (u+\varepsilon)^2 \in (p,1]$. If $a = 1$ (i.e. $\varepsilon = 1-u$), $D(1\|p) = -\ln p = -2\ln u > 2(1-u)^2 = 2\varepsilon^2$ since $-\ln(1-v) > v \geq v^2$. Assume $a < 1$. Then
$$D(a\|p) = 2(u+\varepsilon)^2\ln\!\left(1+\tfrac{\varepsilon}{u}\right) + (1-a)\ln\!\left(\tfrac{1-a}{1-p}\right).$$
Since $\ln(1+z) < z$ for $z > 0$, $(1-a)\ln\frac{1-a}{1-p} = -(1-a)\ln\frac{1-p}{1-a} > -(a-p) = -2u\varepsilon-\varepsilon^2$. Since $\ln(1+x) \geq \frac{2x}{2+x}$ for $x > 0$,
$$2(u+\varepsilon)^2\ln\!\left(1+\tfrac{\varepsilon}{u}\right) \geq \frac{4\varepsilon(u+\varepsilon)^2}{2u+\varepsilon}.$$
Hence $D(a\|p) > \frac{4\varepsilon(u+\varepsilon)^2}{2u+\varepsilon} - 2u\varepsilon - \varepsilon^2 \geq 2\varepsilon^2$, because the difference equals $\frac{\varepsilon^3}{2u+\varepsilon} > 0$. Therefore
$$\mathbb{P}\{\sqrt{B}-\sqrt{np} \geq \varepsilon\sqrt{n}\} \leq e^{-nD(a\|p)} < e^{-2n\varepsilon^2}.$$

*Lower tail.* $\{\sqrt{B}-\sqrt{np} \leq -\varepsilon\sqrt{n}\} = \{\sqrt{B} \leq \sqrt{n}(u-\varepsilon)\}$. If $\varepsilon > u$ or $p \in \{0,1\}$, this probability is $0$. Assume $0 < \varepsilon \leq u < 1$ and set $a' = (u-\varepsilon)^2 < p$. If $a' = 0$ (i.e. $\varepsilon = u$), $D(0\|p) = -\ln(1-p) = -\ln(1-\varepsilon^2) > \varepsilon^2$. Assume $a' > 0$. Then
$$D(a'\|p) = 2(u-\varepsilon)^2\ln\!\left(1-\tfrac{\varepsilon}{u}\right) + (1-a')\ln\!\left(\tfrac{1-a'}{1-p}\right).$$
Since $\ln(1-y) \geq \frac{-y}{1-y}$ for $0 \leq y < 1$, $2(u-\varepsilon)^2\ln(1-\varepsilon/u) \geq -2\varepsilon(u-\varepsilon)$. Writing $\frac{1-a'}{1-p} = 1 + \frac{p-a'}{1-p}$ and using $\ln(1+z) \geq \frac{2z}{2+z}$,
$$(1-a')\ln\!\left(\tfrac{1-a'}{1-p}\right) \geq \frac{2(1-a')(p-a')}{2-p-a'}.$$
Thus $D(a'\|p) > -2\varepsilon(u-\varepsilon) + \frac{2(1-a')(p-a')}{2-p-a'} \geq \varepsilon^2$, with gap $\frac{(p-a')^2}{2-p-a'} > 0$ (using $p - a' = \varepsilon(2u-\varepsilon)$). Therefore
$$\mathbb{P}\{\sqrt{B}-\sqrt{np} \leq -\varepsilon\sqrt{n}\} = \mathbb{P}\{B \leq na'\} \leq e^{-nD(a'\|p)} < e^{-n\varepsilon^2}.$$
