**Central idea.** The left-hand side is $2^n$ times the lower-tail probability $\mathbb{P}\{B \le D\}$ of a symmetric binomial $B \sim \mathrm{Bin}(n,1/2)$. Apply the Cramér–Chernoff method with the exactly optimized exponential parameter $\lambda^* = \log\frac{n-D}{D}$, then simplify using $1+x \le e^x$. The case $D \ge n/2$ is handled separately by monotonicity of $(en/D)^D$.

**Solution.** Let $B \sim \mathrm{Bin}(n, 1/2)$. Then
$$\sum_{j=0}^D \binom{n}{j} = 2^n \mathbb{P}\{B \le D\}.$$

*Case $D \ge n/2$.* Since $\sum_{j=0}^D \binom{n}{j} \le 2^n$, it suffices to show $(en/D)^D \ge 2^n$. The function $f(D) = \log(en/D)^D = D(1+\log n - \log D)$ satisfies $f'(D) = \log(n/D) \ge 0$ for $1 \le D \le n$, so $f$ is increasing and
$$\left(\frac{en}{D}\right)^D \ge \left(\frac{en}{n/2}\right)^{n/2} = (2e)^{n/2} \ge 2^n,$$
where $(2e)^{n/2} \ge 2^n$ follows from $2e \ge 4$.

*Case $1 \le D < n/2$.* By Chernoff's inequality (the Cramér–Chernoff method), for any $\lambda > 0$,
$$\mathbb{P}\{B \le D\} = \mathbb{P}\{e^{-\lambda B} \ge e^{-\lambda D}\} \le e^{\lambda D}\,\mathbb{E}[e^{-\lambda B}] = e^{\lambda D}\left(\frac{1+e^{-\lambda}}{2}\right)^n.$$
Minimize $\phi(\lambda) = \lambda D + n\log(1+e^{-\lambda}) - n\log 2$ over $\lambda > 0$. Since
$$\phi'(\lambda) = D - n\frac{e^{-\lambda}}{1+e^{-\lambda}},$$
the unique minimizer satisfies $\frac{e^{-\lambda}}{1+e^{-\lambda}} = \frac{D}{n}$, i.e. $e^{-\lambda^*} = \frac{D}{\,n-D\,}$, $\lambda^* = \log\frac{n-D}{D} > 0$ (using $D < n/2$). Substituting,
$$\phi(\lambda^*) = D\log\frac{n-D}{D} + n\log\frac{n}{n-D} - n\log 2 = n\log n - n\log 2 - D\log D - (n-D)\log(n-D),$$
hence
$$\sum_{j=0}^D \binom{n}{j} \le 2^n e^{\phi(\lambda^*)} = \frac{n^n}{D^D\,(n-D)^{\,n-D}}.$$
It remains to show $\frac{n^n}{D^D(n-D)^{n-D}} \le \left(\frac{en}{D}\right)^D = \frac{e^D n^D}{D^D}$, i.e.
$$n^{\,n-D} \le e^D (n-D)^{\,n-D} \quad\Longleftrightarrow\quad \left(1+\frac{D}{n-D}\right)^{n-D} \le e^D.$$
This follows from $1+x \le e^x$ with $x = D/(n-D)$:
$$\left(1+\frac{D}{n-D}\right)^{n-D} \le \exp\left(\frac{D}{n-D}\cdot(n-D)\right) = e^D.$$
This completes the proof.
