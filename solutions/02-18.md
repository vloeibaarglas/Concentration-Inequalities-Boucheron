**Central idea.** The maximal inequality (Theorem 2.5, cited as Theorem 2.4 in the exercise: Jensen + union bound) gives $\mathbb{E}\max_i X_i \le \inf_{\lambda>0}\frac{\log n + e^{\lambda}-1}{\lambda}$ using the Poisson MGF $\mathbb{E}e^{\lambda X} = e^{e^{\lambda}-1}$. The exact optimizer solves $e^{\lambda}(\lambda-1) = \log(n/e)$, i.e. $\lambda = 1+W(\log(n/e)/e)$, yielding the Lambert $W$ bound. The "manageable" bound is just this inequality evaluated at the convenient (non-optimal) choice $\lambda = \log\log(en)$.

**Erratum.** The statement's hypothesis "$n \ge e^3$" for the explicit (second) bound is wrong as printed, and the hint's "Theorem 2.4" should read Theorem 2.5 (the maximal inequality; the book has only a Lemma 2.4). Write $z = \log(n/e)/e$. At $n = e^3$, $z = 2/e < 1$, so $\log(\log(n/e)/e) = \log(2/e) < 0$ and the logarithm in the denominator is undefined. For $1 < z < e$ the right side is defined but the bound is *false*: at $n = 160$ ($z \approx 1.499$) the explicit right side equals $3.113$, while the true value is $\mathbb{E}\max_{i\le 160} X_i = \sum_{k\ge0}\bigl(1-F(k)^{160}\bigr) = 4.503$ ($F$ the Poisson$(1)$ cdf; the Lambert $W$ bound there is $5.616$, consistent). The lower bound $W(z) \ge \log z - \log\log z$ requires $z \ge e$, so the corrected statement, proved below, is: the explicit bound holds for $n \ge e^{e^2+1} \approx 4399$. (The Lambert $W$ bound and the "manageable" bound hold as printed.)

**Solution.** For $X \sim \mathrm{Poisson}(1)$, $\mathbb{E}[e^{\lambda X}] = \sum_{k\ge0} e^{\lambda k}e^{-1}/k! = e^{e^{\lambda}-1}$ for $\lambda \in \mathbb{R}$. By the maximal inequality (Theorem 2.5, cited as Theorem 2.4 in the exercise),
$$\exp\!\left(\lambda\,\mathbb{E}\max_{1\le i\le n} X_i\right) \le \sum_{i=1}^n \mathbb{E}[e^{\lambda X_i}] = n\,e^{e^{\lambda}-1}, \qquad \lambda > 0,$$
so with $f(\lambda) = \frac{\log n + e^{\lambda}-1}{\lambda}$,
$$\mathbb{E}\max_{1\le i\le n} X_i \le \inf_{\lambda>0} f(\lambda). \tag{1}$$

*Lambert $W$ bound.* $f'(\lambda) = \frac{\lambda e^{\lambda} - (\log n + e^{\lambda}-1)}{\lambda^2}$, so $f'(\lambda) = 0$ iff
$$e^{\lambda}(\lambda-1) = \log n - 1 = \log(n/e).$$
Writing $u = \lambda-1$ gives $ue^{u} = \log(n/e)/e$, i.e. $u = W(\log(n/e)/e)$, where $W = W_0$ is the principal branch of Lambert $W$ (defined since $\log(n/e)/e \ge -1/e$ for $n \ge 1$; for $1 < n < e$ the argument lies in $(-1/e,0)$ where $W$ has two real branches, and $W_0 > -1$ is the one giving $\lambda^* > 0$). Thus the unique minimizer ( $f \to +\infty$ at both ends) is $\lambda^* = 1 + W(\log(n/e)/e) > 0$ for $n > 1$ (for $n=1$ both sides equal $1$). At the optimum, $\log n - 1 = e^{\lambda^*}(\lambda^*-1)$, so
$$f(\lambda^*) = \frac{e^{\lambda^*}(\lambda^*-1) + e^{\lambda^*}}{\lambda^*} = e^{\lambda^*} = e\cdot e^{W} = e\cdot\frac{\log(n/e)}{e\,W(\log(n/e)/e)} = \frac{\log(n/e)}{W(\log(n/e)/e)},$$
using $We^{W} = \log(n/e)/e$. With (1),
$$\mathbb{E}\max_{1\le i\le n} X_i \le \frac{\log(n/e)}{W(\log(n/e)/e)}.$$

*Lower bound for $W$.* Let $z \ge e$ and $w = W(z)$, so $we^{w} = z$. Set $w_0 = \log z - \log\log z \ge 1 > -1$ (the minimum of $\log z - \log\log z$ on $[e,\infty)$ is $1$, attained at $z=e$). Then
$$w_0e^{w_0} = (\log z - \log\log z)\,\frac{z}{\log z} = z\left(1-\frac{\log\log z}{\log z}\right) \le z = we^{w}.$$
Since $x \mapsto xe^{x}$ is strictly increasing on $[-1,\infty)$, $w_0 \le w$, i.e.
$$W(z) \ge \log z - \log\log z, \qquad z \ge e.$$

*Combined bound.* Applying this with $z = \log(n/e)/e$ gives, whenever $z \ge e$ (i.e. $n \ge e^{e^2+1}$),
$$\mathbb{E}\max_{1\le i\le n} X_i \le \frac{\log(n/e)}{\log(\log(n/e)/e) - \log(\log(\log(n/e)/e))}.$$
(See the Erratum: for $n \ge e^3$ alone this fails — e.g. at $n = 160$ the right side is $3.113 < 4.503 = \mathbb{E}\max_i X_i$.)

*Manageable bound.* Evaluate (1) directly at $\lambda = \log\log(en) > 0$ (for $n \ge 2$): since $e^{\lambda} = \log(en) = 1+\log n$,
$$\mathbb{E}\max_{1\le i\le n} X_i \le \frac{\log n + (1+\log n) - 1}{\log\log(en)} = \frac{2\log n}{\log(\log(en))}.$$
