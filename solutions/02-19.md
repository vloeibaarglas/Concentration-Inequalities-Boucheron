**Central idea.** A Binomial$(m,p)$ moment-generating function is dominated by that of a Poisson$(mp)$ variable, since $1-p+pe^{\lambda}\leq e^{p(e^{\lambda}-1)}$. Feeding this into the maximal-inequality Chernoff argument (Jensen's inequality plus $\max_i a_i\leq\sum_i a_i$ — the estimate at the heart of Theorem 2.5, cited as Theorem 2.4 in the exercise) gives $\mathbb{E}\max_i X_i\leq\inf_{\lambda>0}\frac{\log n+mp(e^{\lambda}-1)}{\lambda}$; the minimizer satisfies $ue^u=\frac{\log n-mp}{emp}$ with $u=\lambda-1$, which is exactly the Lambert $W$ function.

**Solution.** Write $\mu=mp$. For $X\sim\mathrm{Binomial}(m,p)$ and $\lambda>0$,
$$\mathbb{E}e^{\lambda X}=(1-p+pe^{\lambda})^m\leq e^{mp(e^{\lambda}-1)}=e^{\mu(e^{\lambda}-1)},$$
using $1+x\leq e^x$ with $x=p(e^{\lambda}-1)$.

For any $\lambda>0$, since $0\leq\max_i X_i\leq m$ (so Jensen applies to the bounded variable $\log e^{\lambda\max_i X_i}$),
$$\mathbb{E}\max_{1\leq i\leq n}X_i=\frac{1}{\lambda}\mathbb{E}\log e^{\lambda\max_i X_i}\leq\frac{1}{\lambda}\log\mathbb{E}e^{\lambda\max_i X_i}=\frac{1}{\lambda}\log\mathbb{E}\max_i e^{\lambda X_i}\leq\frac{1}{\lambda}\log\sum_{i=1}^n\mathbb{E}e^{\lambda X_i}\leq\frac{\log n+\mu(e^{\lambda}-1)}{\lambda},$$
using $\max_i a_i\leq\sum_i a_i$ for $a_i\geq0$. Hence, with $f(\lambda)=\frac{\log n+\mu(e^{\lambda}-1)}{\lambda}$,
$$\mathbb{E}\max_i X_i\leq\inf_{\lambda>0}f(\lambda).$$

For $n=1$, $\mathbb{E}\max_i X_i=\mu$ while the claimed bound equals $\mu e^{1+W(-1/e)}=\mu$; assume $n\geq2$. Then $f$ is continuous on $(0,\infty)$ with $f(\lambda)\to+\infty$ as $\lambda\to0^+$ (numerator $\to\log n>0$) and as $\lambda\to\infty$, so the infimum is attained. Moreover
$$f'(\lambda)=\frac{\mu e^{\lambda}\lambda-\log n-\mu e^{\lambda}+\mu}{\lambda^2},$$
so $f'(\lambda)=0$ iff $\mu e^{\lambda}(\lambda-1)=\log n-\mu$. Since $h(\lambda)=\mu e^{\lambda}(\lambda-1)$ satisfies $h'(\lambda)=\mu\lambda e^{\lambda}>0$ on $(0,\infty)$, it is strictly increasing, hence there is a unique critical point, which is the global minimizer.

Put $u=\lambda-1$: then $\mu e^{u+1}u=\log n-\mu$, i.e.
$$ue^u=\frac{\log n-\mu}{e\mu}.$$
Since $\log n\geq0$, $\frac{\log n-\mu}{e\mu}\geq-\frac{1}{e}$ (strictly $>$ for $n\geq2$), so with $W = W_0$ the principal branch of Lambert $W$ (the relevant branch when the argument lies in $(-1/e,0)$, i.e. when $\log n < \mu$), $u=W\!\left(\frac{\log n-\mu}{e\mu}\right)>-1$ and $\lambda^*=1+u>0$. Now
$$f(1+u)=\frac{\log n+\mu e^{1+u}-\mu}{1+u}.$$
From $ue^u=\frac{\log n-\mu}{e\mu}$ we get $\log n-\mu=e\mu ue^u$, so the numerator equals $e\mu ue^u+\mu e\cdot e^u=\mu e^{1+u}(u+1)$, and
$$f(1+u)=\mu e^{1+u}=\mu e^{1+W((\log n-\mu)/(e\mu))}.$$
With $\mu=mp$ this is
$$\mathbb{E}\max_{i=1,\ldots,n}X_i\leq mpe^{1+W((\log(n)-mp)/(emp))},$$
as claimed.
