**Central idea.** The sub-Gaussian-type tail bound makes $X$ integrable, so $|M_X - \mathbb{E}X| \leq \mathbb{E}|X - M_X|$. Write the mean absolute deviation as a tail integral $\int_0^\infty \mathbb{P}\{|X-M_X| > t\}\,dt$ and bound it two ways: directly (giving $a\sqrt{b\pi}/2$) and via $\mathbb{E}[Y] \leq \sqrt{\mathbb{E}[Y^2]}$ with $\mathbb{E}[Y^2] = \int_0^\infty 2t\,\mathbb{P}\{Y>t\}\,dt$ (giving $\sqrt{ab}$).

**Solution.** Let $M = M_X$ and $Y = |X - M_X| \geq 0$. By hypothesis, $\mathbb{P}\{Y > t\} \leq ae^{-t^2/b}$ for all $t > 0$.

First, $\mathbb{E}Y = \int_0^\infty \mathbb{P}\{Y > t\}\,dt \leq \int_0^\infty ae^{-t^2/b}\,dt < \infty$, so $\mathbb{E}|X| \leq |M| + \mathbb{E}Y < \infty$ and $\mathbb{E}X$ exists. By Jensen,
$$|M_X - \mathbb{E}X| = |\mathbb{E}(M_X - X)| \leq \mathbb{E}|X - M_X| = \mathbb{E}Y.$$

*Bound 1.* Using $\mathbb{P}\{Y > t\} \leq ae^{-t^2/b}$ directly:
$$\mathbb{E}Y \leq \int_0^\infty ae^{-t^2/b}\,dt = a\sqrt{b}\int_0^\infty e^{-u^2}\,du = \frac{a\sqrt{b\pi}}{2} \leq a\sqrt{\frac{b\pi}{2}},$$
via $u = t/\sqrt{b}$ and $\int_0^\infty e^{-u^2}du = \sqrt{\pi}/2$.

*Bound 2.* By Cauchy–Schwarz, $\mathbb{E}Y \leq \sqrt{\mathbb{E}[Y^2]}$, and
$$\mathbb{E}[Y^2] = \int_0^\infty 2t\,\mathbb{P}\{Y > t\}\,dt \leq \int_0^\infty 2t\,ae^{-t^2/b}\,dt = 2a\cdot\frac{b}{2} = ab,$$
since $\int_0^\infty 2te^{-t^2/b}dt = b$ (substitute $s = t^2/b$). Hence $\mathbb{E}Y \leq \sqrt{ab}$.

Therefore $|M_X - \mathbb{E}X| \leq \min\left(\sqrt{ab},\, a\sqrt{b\pi}/2\right) \leq \min\left(\sqrt{ab},\, a\sqrt{b\pi/2}\right)$.
