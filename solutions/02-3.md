**Central idea.** (Chebyshev–Cantelli.) Shift $Y$ by a free parameter $a > 0$ before applying Chebyshev: $\mathbb{P}\{Y - \mu \geq t\} = \mathbb{P}\{Y - \mu + a \geq t + a\} \leq (\sigma^2 + a^2)/(t+a)^2$. Optimizing over $a$ (best choice $a = \sigma^2/t$) yields $\sigma^2/(\sigma^2 + t^2)$, strictly better than Chebyshev's $\sigma^2/t^2$.

**Solution.** If $\mathrm{Var}(Y) = \infty$, the right-hand side is $1$ and there is nothing to prove. If $\mathrm{Var}(Y) = 0$, then $Y = \mathbb{E}Y$ a.s. and both sides are $0$. Assume $0 < \sigma^2 := \mathrm{Var}(Y) < \infty$ (hence $\mathbb{E}|Y| < \infty$), and write $\mu = \mathbb{E}Y$.

For any $a > 0$,
$$\mathbb{P}\{Y - \mu \geq t\} = \mathbb{P}\{Y - \mu + a \geq t + a\} \leq \frac{\mathbb{E}[(Y - \mu + a)^2]}{(t+a)^2}$$
by Markov's inequality applied to $(Y-\mu+a)^2$. Since $\mathbb{E}[Y-\mu] = 0$,
$$\mathbb{E}[(Y-\mu+a)^2] = \mathbb{E}[(Y-\mu)^2] + 2a\,\mathbb{E}[Y-\mu] + a^2 = \sigma^2 + a^2.$$
Thus $\mathbb{P}\{Y - \mu \geq t\} \leq \frac{\sigma^2+a^2}{(t+a)^2}$ for all $a > 0$.

Minimize $f(a) = \frac{\sigma^2+a^2}{(t+a)^2}$ over $a > 0$:
$$f'(a) = \frac{2a(t+a)^2 - 2(t+a)(\sigma^2+a^2)}{(t+a)^4} = \frac{2(at - \sigma^2)}{(t+a)^3},$$
so $f$ decreases on $(0, \sigma^2/t)$ and increases on $(\sigma^2/t, \infty)$, with minimum at $a = \sigma^2/t$. Substituting,
$$f(\sigma^2/t) = \frac{\sigma^2 + \sigma^4/t^2}{(t + \sigma^2/t)^2} = \frac{\sigma^2(t^2+\sigma^2)/t^2}{(t^2+\sigma^2)^2/t^2} = \frac{\sigma^2}{\sigma^2+t^2}.$$
Hence $\mathbb{P}\{Y - \mathbb{E}Y \geq t\} \leq \frac{\mathrm{Var}(Y)}{\mathrm{Var}(Y)+t^2}$.
