**Central idea.** The Section 3.6 proof bounds $b-a$ by comparing a variance lower bound for the truncated function $g_{a,b}$ (coming from $\mathbb{P}\{Z \ge b\}$) against an Efron–Stein upper bound. Here the hypothesis controls *upward* jumps, $\sum_i (Z'_i-Z)_+^2 \le v$, so by the exchangeability of the pair $(X,\tilde X^{(i)})$ we flip the Efron–Stein sum to $\sum_i \mathbb{E}(g_{a,b}(\tilde X^{(i)})-g_{a,b}(X))_+^2$. The uniform bound $B$ implies each summand vanishes on $\{Z \le a-B\}$; shifting the lower truncation level to $a = Q_{1-\gamma}+B$ then turns the leftover indicator into $\mathbb{P}\{Z > Q_{1-\gamma}\} \le \gamma$, at the price of the extra $B$ in the final estimate.

**Solution.** Write $Z = f(X)$ and $Z'_i = f(\tilde X^{(i)})$, where $\tilde X^{(i)}$ is $X$ with the $i$-th coordinate replaced by an independent copy. By definition of $B$, $|Z - Z'_i| \le B$ almost surely for every $i$, and by hypothesis
$$\sum_{i=1}^n (Z'_i - Z)_+^2 = \sum_{i=1}^n (Z - Z'_i)_-^2 \le v \quad \text{a.s.}$$
Fix $0 < \delta < \gamma \le 1/2$ with $Q_{1-\gamma} \ge MZ + B$, and set
$$a = Q_{1-\gamma} + B, \qquad b = Q_{1-\delta}.$$
If $b \le a$ there is nothing to prove, since then $Q_{1-\delta} - Q_{1-\gamma} \le B$. Assume $b > a$, so that with $g_{a,b}$ defined as in Section 3.6 ($g_{a,b}(x) = b$ if $f(x) \ge b$, $f(x)$ if $a < f(x) < b$, $a$ if $f(x) \le a$), the truncation is non-degenerate. Note that $a \ge MZ$ by hypothesis.

*Lower bound.* Since $\mathbb{P}\{Z > a\} \le \mathbb{P}\{Z > Q_{1-\gamma}\} \le \gamma \le 1/2$,
$$\mathbb{E} g_{a,b}(X) \le a\,\mathbb{P}\{Z \le a\} + b\,\mathbb{P}\{Z > a\} \le \frac{a+b}{2},$$
and therefore, as in Section 3.6,
$$\mathrm{Var}(g_{a,b}(X)) \ge \mathbb{P}\{g_{a,b}(X) = b\}\,(b - \mathbb{E} g_{a,b}(X))^2 \ge \frac{\mathbb{P}\{Z \ge b\}}{4}\,(b-a)^2.$$

*Upper bound.* By the Efron–Stein inequality and the exchangeability of $(X,\tilde X^{(i)})$,
$$\mathrm{Var}(g_{a,b}(X)) \le \sum_{i=1}^n \mathbb{E}\big(g_{a,b}(X) - g_{a,b}(\tilde X^{(i)})\big)^2 = 2\sum_{i=1}^n \mathbb{E}\big(g_{a,b}(\tilde X^{(i)}) - g_{a,b}(X)\big)_+^2.$$
Since $g_{a,b}$ is nondecreasing and $1$-Lipschitz, $(g_{a,b}(\tilde X^{(i)}) - g_{a,b}(X))_+ \le (Z'_i - Z)_+$ pointwise. Moreover, on the event $\{Z \le a - B\}$ we have $Z'_i \le Z + B \le a$ for every $i$, hence $g_{a,b}(\tilde X^{(i)}) = a \le g_{a,b}(X)$ and the positive part vanishes. Consequently,
$$\sum_{i=1}^n \big(g_{a,b}(\tilde X^{(i)}) - g_{a,b}(X)\big)_+^2 \le \mathbf{1}_{\{Z > a-B\}} \sum_{i=1}^n (Z'_i - Z)_+^2 \le v\,\mathbf{1}_{\{Z > a-B\}} \quad \text{a.s.},$$
and taking expectations,
$$\mathrm{Var}(g_{a,b}(X)) \le 2v\,\mathbb{P}\{Z > a - B\} = 2v\,\mathbb{P}\{Z > Q_{1-\gamma}\} \le 2v\gamma.$$

*Conclusion.* Comparing the two bounds and using $\mathbb{P}\{Z \ge b\} = \mathbb{P}\{Z \ge Q_{1-\delta}\} \ge \delta$,
$$\frac{\delta}{4}(b-a)^2 \le 2v\gamma, \qquad\text{i.e.}\qquad b - a \le \sqrt{\frac{8v\gamma}{\delta}}.$$
Since $b - a = Q_{1-\delta} - Q_{1-\gamma} - B$, this is exactly
$$Q_{1-\delta} - Q_{1-\gamma} \le B + \sqrt{\frac{8v\gamma}{\delta}},$$
as claimed.
