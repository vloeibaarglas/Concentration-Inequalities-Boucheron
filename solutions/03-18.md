**Central idea.** For self-bounding $Z \ge 0$, the square root $W = \sqrt{Z}$ itself satisfies condition (3.4) with the *universal* constant $v = 1$: indeed $(\sqrt{Z}-\sqrt{Z'_i})_+ \le (Z-Z'_i)_+/\sqrt{Z}$, while self-bounding gives $\sum_i (Z-Z'_i)_+^2 \le \sum_i (Z-Z'_i)_+ \le Z$. Applying the Section 3.6 quantile argument to $W$ — whose quantiles are $\sqrt{a_k}$ — yields $\sqrt{a_{k+1}}-\sqrt{a_k} \le 4$. (The problem's "$ck$" is a typo for a universal constant $c$: with a growing bound the claimed $e^{-\sqrt{t}/C}$ tail would not follow.) Telescoping the quantile gaps then gives the sub-exponential upper tail.

**Erratum.** The statement is wrong as printed in two respects. (i) Rate: a gap bound $\sqrt{a_{k+1}}-\sqrt{a_k}\le ck$ telescopes only to $\sqrt{a_m}\lesssim m^2$, which gives an $e^{-t^{1/4}}$-type tail, so "which implies" fails; the provable gap bound is $\sqrt{a_{k+1}}-\sqrt{a_k}\le c$ with a universal $c$ (here $c=4$). (ii) Constant: the tail $\mathbb{P}\{Z>MZ+t\}\le Ce^{-\sqrt t/C}$ cannot hold with $C$ universal; $C$ must be allowed to depend on $MZ$. Counterexample: $Z=\sum_{i=1}^n X_i$ with $X_i$ iid Bernoulli$(1/2)$ is self-bounding ($f_i=\sum_{j\ne i}X_j$), $MZ=n/2$, and $\sqrt n$ is two standard deviations, so $\mathbb{P}\{Z>MZ+\sqrt n\}\to\mathbb{P}\{N(0,1)>2\}\approx0.023$ (exact binomial values: $0.0231$ at $n=10^3$, $0.0227$ at $n=10^6$), whereas a universal $C$ would force $Ce^{-n^{1/4}/C}\to0$. The corrected statement, proved below, is: $\sqrt{a_{k+1}}-\sqrt{a_k}\le4$ for $k\ge1$, and $\mathbb{P}\{Z>MZ+t\}\le e^{-\frac{\ln 2}{8}\sqrt t}$ for $t\ge\max(64,16MZ)$, hence $\mathbb{P}\{Z>MZ+t\}\le Ce^{-\sqrt t/C}$ for all $t>0$ with $C$ depending on $MZ$.

**Solution.** Recall that $f$ self-bounding means there are functions $f_i$ of all coordinates but the $i$-th with $0 \le f(x) - f_i(x^{(i)}) \le 1$ for all $x,i$ and $\sum_{i=1}^n (f(x)-f_i(x^{(i)})) \le f(x)$; in particular $Z = f(X) \ge 0$. Write $Z'_i = f(\tilde X^{(i)})$ with $\tilde X^{(i)}$ the vector $X$ with $X_i$ replaced by an independent copy.

We first record two consequences. Since $f_i$ does not depend on coordinate $i$,
$$f(\tilde X^{(i)}) \ge f_i\big((\tilde X^{(i)})^{(i)}\big) = f_i(X^{(i)}),$$
so that
$$Z - Z'_i = f(X) - f(\tilde X^{(i)}) \le f(X) - f_i(X^{(i)}) \le 1 \quad \text{a.s.}$$
Hence $(Z-Z'_i)_+ \le 1$ and $(Z-Z'_i)_+^2 \le (Z-Z'_i)_+$. Moreover, $(Z-Z'_i)_+ \le (f(X)-f_i(X^{(i)}))_+ = f(X)-f_i(X^{(i)})$, so
$$\sum_{i=1}^n (Z-Z'_i)_+ \le \sum_{i=1}^n \big(f(X)-f_i(X^{(i)})\big) \le Z \quad \text{a.s.}$$

Now set $W = \sqrt{Z} \ge 0$ and $W'_i = \sqrt{Z'_i}$. For $Z > 0$,
$$0 \le (W - W'_i)_+ = (\sqrt{Z}-\sqrt{Z'_i})_+ = \frac{(Z-Z'_i)_+}{\sqrt{Z}+\sqrt{Z'_i}} \le \frac{(Z-Z'_i)_+}{\sqrt{Z}},$$
and for $Z = 0$ the left side is $0$. Therefore, with the convention $0/0 = 0$,
$$\sum_{i=1}^n (W-W'_i)_+^2 \le \frac{1}{Z}\sum_{i=1}^n (Z-Z'_i)_+^2 \le \frac{1}{Z}\sum_{i=1}^n (Z-Z'_i)_+ \le 1 \quad \text{a.s.},$$
i.e. $W$ satisfies condition (3.4) of Section 3.6 with the universal constant $v = 1$.

Apply the Section 3.6 argument to $W$. With $b_k = Q_{1-2^{-k}}(W) = \sqrt{a_k}$ (quantiles commute with the increasing map $z \mapsto \sqrt{z}$) and $k \ge 1$,
$$b_{k+1} - b_k \le \sqrt{\frac{8v \cdot 2^{-k}}{2^{-(k+1)}}} = 4\sqrt{v} = 4,$$
that is,
$$\sqrt{a_{k+1}} - \sqrt{a_k} \le 4 \qquad (k \ge 1).$$
Telescoping from $a_1 = Q_{1/2} = MZ$ gives $\sqrt{a_m} \le \sqrt{MZ} + 4(m-1)$ for $m \ge 1$.

For the tail bound, let $t > 0$ and take $m = \lfloor \sqrt{t}/8 \rfloor$. If $t \ge \max(64, 16MZ)$ then $m \ge 1$ and
$$a_{m+1} \le \big(\sqrt{MZ}+4m\big)^2 = MZ + 8m\sqrt{MZ} + 16m^2 \le MZ + \sqrt{tMZ} + \frac{t}{4} \le MZ + t,$$
using $m \le \sqrt{t}/8$ and $\sqrt{tMZ} \le t/4$. Hence $\{Z > MZ+t\} \subseteq \{Z > a_{m+1}\}$ and
$$\mathbb{P}\{Z > MZ + t\} \le \mathbb{P}\{Z > a_{m+1}\} \le 2^{-(m+1)} \le e^{-\frac{\ln 2}{8}\sqrt{t}}.$$
For $0 < t < \max(64,16MZ)$ the same bound holds up to a prefactor depending only on $MZ$. Thus for a constant $C$ (depending at most on $MZ$; by the Erratum, no universal $C$ exists),
$$\mathbb{P}\{Z > MZ + t\} \le C e^{-\sqrt{t}/C} \qquad \text{for all } t > 0,$$
as claimed. In particular the upper tail of a self-bounding function is sub-exponential in $\sqrt{t}$.
