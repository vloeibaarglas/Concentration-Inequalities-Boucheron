**Central idea.** Apply the Efron–Stein inequality $\mathrm{Var}(Z) \le \sum_{i=1}^n \mathbb{E}[\mathrm{Var}_i(Z)]$, where $\mathrm{Var}_i$ is the variance conditionally on all variables except $X_i$. Given $X_{-i}$, $Z$ is a function $\phi$ of the binary $X_i$ alone; for $\mathbb{P}\{X_i = 1\} = p_i$, $\mathrm{Var}(\phi(X_i)) = p_i(1-p_i)(\phi(1) - \phi(-1))^2$, and bounded differences gives $(\phi(1)-\phi(-1))^2 \le c_i^2$.

**Solution.** Let $\mathrm{Var}_i(Z) = \mathrm{Var}(Z \mid X_{-i})$ denote conditional variance given all variables except $X_i$. The Efron–Stein inequality gives
$$\mathrm{Var}(Z) \le \sum_{i=1}^n \mathbb{E}[\mathrm{Var}_i(Z)].$$
Fix $i$ and condition on $X_{-i} = x_{-i}$. Write $\phi(t) = f(x_{-i}, t)$ for $t \in \{-1, 1\}$, so that conditionally $Z = \phi(X_i)$ with $X_i$ binary, $\mathbb{P}\{X_i = 1\} = p_i$. For $a = \phi(1)$, $b = \phi(-1)$,
\begin{align*}
\mathrm{Var}(\phi(X_i)) &= p_i a^2 + (1-p_i) b^2 - \big(p_i a + (1-p_i) b\big)^2 \\
&= p_i(1-p_i)(a - b)^2 = p_i(1-p_i)\big(\phi(1) - \phi(-1)\big)^2.
\end{align*}
The bounded differences property gives $|\phi(1) - \phi(-1)| = |f(x_{-i}, 1) - f(x_{-i}, -1)| \le c_i$, uniformly in $x_{-i}$. Hence $\mathrm{Var}_i(Z) \le p_i(1-p_i) c_i^2$ a.s., and taking expectations,
$$\mathbb{E}[\mathrm{Var}_i(Z)] \le p_i(1-p_i) c_i^2.$$
Summing over $i$ yields $\mathrm{Var}(Z) \le \sum_{i=1}^n c_i^2 p_i(1-p_i)$. ∎
