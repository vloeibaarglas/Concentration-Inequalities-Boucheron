**Central idea.** Assume the $X_i$ i.i.d., so each $Z_i$ has the law of $f_{\,n-1}$ on $n-1$ samples. Write $b_m = \mathbb{E}f_m - \theta$ for the bias at sample size $m$. Then $\mathbb{E}\tilde{Z} - \theta = n b_n - (n-1)b_{\,n-1}$; the $c/n$ terms cancel exactly ($n \cdot c/n - (n-1)\cdot c/(n-1) = 0$), which is the jackknife's bias correction. (Remark below on the remainder: the $O(n^{-2})$ conclusion as stated needs the bias expansion to second order.)

**Solution.** Assume $X_1, \ldots, X_n$ i.i.d. By symmetry $\mathbb{E}Z_i$ is independent of $i$, each $Z_i$ having the distribution of $f_{\,n-1}$ applied to $n-1$ i.i.d.\ copies. Let $b_m = \mathbb{E}f_m(X_1,\ldots,X_m) - \theta$, so $b_m = c/m + O(m^{-2})$. Then
\begin{align*}
\mathbb{E}\tilde{Z} - \theta &= \mathbb{E}Z - (n-1)\Big(\frac1n\sum_{i=1}^n \mathbb{E}Z_i - \mathbb{E}Z\Big) - \theta \\
&= n(\mathbb{E}Z - \theta) - (n-1)(\mathbb{E}Z_1 - \theta) \\
&= n b_n - (n-1) b_{\,n-1}.
\end{align*}
Inserting $b_m = c/m + \rho_m$ with $\rho_m = O(m^{-2})$,
$$n b_n - (n-1)b_{\,n-1} = \Big(c + n\rho_n\Big) - \Big(c + (n-1)\rho_{\,n-1}\Big) = n\rho_n - (n-1)\rho_{\,n-1},$$
so the order-$1/n$ bias cancels: this is Quenouille's correction.

*Remark on the remainder.* As stated, the hypothesis $b_n = c/n + O(n^{-2})$ only yields $n\rho_n - (n-1)\rho_{\,n-1} = O(n^{-1})$ in the worst case: e.g.\ $\rho_n = (-1)^n/n^2$ gives $n\rho_n - (n-1)\rho_{\,n-1} = (-1)^n(2n-1)/(n(n-1))$, which is $\asymp 1/n$, not $O(n^{-2})$. The $O(n^{-2})$ conclusion holds under the classical smooth two-term expansion $b_n = c/n + d/n^2 + O(n^{-3)}$ (Quenouille's setting), for which
$$n b_n - (n-1)b_{\,n-1} = d\Big(\frac1n - \frac1{\,n-1\,}\Big) + O(n^{-2}) = -\frac{d}{n(n-1)} + O(n^{-2}) = O(n^{-2}).$$
In applications the bias is smooth in $1/n$, so the jackknife indeed reduces the bias from order $1/n$ to order $1/n^2$. ∎
