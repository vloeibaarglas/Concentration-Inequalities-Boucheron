**Central idea.** Apply Efron–Stein: $\mathrm{Var}(f(X)) \le \sum_{i=1}^n \mathbb{E}[\mathrm{Var}_i(f(X))]$. Each coordinate slice $t \mapsto f(x_{-i}, t)$ is $1$-Lipschitz (from $\ell^1$-Lipschitzness of $f$), and a $1$-Lipschitz map cannot increase variance: $\mathrm{Var}(\phi(X_i)) = \tfrac12\mathbb{E}[(\phi(X_i)-\phi(X_i'))^2] \le \tfrac12\mathbb{E}[(X_i-X_i')^2] = \mathrm{Var}(X_i)$ for $X_i'$ an independent copy. Summing gives $\mathrm{Var}(f(X)) \le \sum_i \mathrm{Var}(X_i) = \mathrm{Var}(\sum_i X_i)$, attained at $f(x) = \sum_i x_i \in \mathcal{F}$.

**Solution.** Let $X_1, \ldots, X_n$ be independent with $\mathrm{Var}(X_i) < \infty$ and $f \in \mathcal{F}$. Since $|f(x)| \le |f(0)| + \sum_i |x_i|$, $f(X)$ has finite second moment, so the Efron–Stein inequality applies:
$$\mathrm{Var}(f(X)) \le \sum_{i=1}^n \mathbb{E}[\mathrm{Var}_i(f(X))],$$
where $\mathrm{Var}_i$ conditions on $X_{-i} = (X_j)_{j \ne i}$.

Fix $x_{-i}$ and set $\phi_{x_{-i}}(t) = f(x_{-i}, t)$. From $\ell^1$-Lipschitzness,
$$|\phi_{x_{-i}}(s) - \phi_{x_{-i}}(t)| = |f(x_{-i}, s) - f(x_{-i}, t)| \le |s - t|,$$
so each slice is $1$-Lipschitz. Conditionally on $X_{-i} = x_{-i}$, $f(X) = \phi_{x_{-i}}(X_i)$ with $X_i$ independent of $x_{-i}$. For any $1$-Lipschitz $\phi$ and $X_i'$ an independent copy of $X_i$,
$$\mathrm{Var}(\phi(X_i)) = \tfrac12\,\mathbb{E}\big[(\phi(X_i) - \phi(X_i'))^2\big] \le \tfrac12\,\mathbb{E}\big[(X_i - X_i')^2\big] = \mathrm{Var}(X_i),$$
using $\mathrm{Var}(W) = \frac12\mathbb{E}[(W-W')^2]$. Hence $\mathrm{Var}_i(f(X)) \le \mathrm{Var}(X_i)$ a.s., and
$$\mathrm{Var}(f(X)) \le \sum_{i=1}^n \mathrm{Var}(X_i).$$
By independence, $\sum_i \mathrm{Var}(X_i) = \mathrm{Var}(\sum_i X_i)$. The function $f_0(x) = \sum_{i=1}^n x_i$ satisfies $|f_0(x) - f_0(y)| \le \sum_i |x_i - y_i|$, so $f_0 \in \mathcal{F}$, and $\mathrm{Var}(f_0(X)) = \sum_i \mathrm{Var}(X_i)$. Thus the maximum of $\mathrm{Var}(f(X))$ over $\mathcal{F}$ is attained at the sum. ∎
