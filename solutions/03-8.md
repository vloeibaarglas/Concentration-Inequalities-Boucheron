**Central idea.** Write $Z=\sum_{k\ge 1}I_k$ with $I_k=\mathbf 1_{\{k\text{ appears}\}}$. Then $\mathbb{E}[Z]/n=\frac1n\sum_k(1-(1-p_k)^n)\to 0$ by dominated convergence, since $(1-(1-p_k)^n)/n\le p_k$ is summable. The variance is explicit from $\mathrm{Var}(I_k)$ and $\mathrm{Cov}(I_k,I_l)=(1-p_k-p_l)^n-(1-p_k)^n(1-p_l)^n\le 0$ (distinct values compete, so indicators are negatively correlated). $Z$ is $(1,0)$-self-bounding (deleting one observation removes at most one distinct value; the number of effective deletions is at most $Z$), so Efron–Stein gives $\mathrm{Var}(Z)\le\mathbb{E}[Z]$ — a bound that ignores the negative correlations and is therefore strictly looser than the explicit formula.

**Solution.** Let $X_1,\dots,X_n$ be iid with $\mathbb{P}\{X_1=k\}=p_k$, $k=1,2,\dots$, $\sum_kp_k=1$. Let $Z=|\{X_1,\dots,X_n\}|$ and $I_k=\mathbf 1_{\{\exists i:X_i=k\}}$, so $Z=\sum_{k\ge 1}I_k$.

*Mean.* $\mathbb{E}[I_k]=1-(1-p_k)^n$, hence $\mathbb{E}[Z]=\sum_k(1-(1-p_k)^n)$. Since $1-(1-x)^n\le nx$ for $x\in[0,1]$,
$$\frac{1-(1-p_k)^n}{n}\le p_k,\qquad\sum_kp_k=1<\infty,$$
and $\frac{1-(1-p_k)^n}{n}\to 0$ for each $k$. By dominated convergence,
$$\frac{\mathbb{E}[Z]}{n}=\sum_{k\ge 1}\frac{1-(1-p_k)^n}{n}\longrightarrow 0.$$

*Variance.* $\mathrm{Var}(I_k)=(1-(1-p_k)^n)(1-p_k)^n$. For $k\ne l$,
\begin{align*}
\mathbb{E}[I_kI_l]&=\mathbb{P}\{k\text{ and }l\text{ both appear}\}\\
&=1-(1-p_k)^n-(1-p_l)^n+(1-p_k-p_l)^n,
\end{align*}
so with $\mathbb{E}[I_k]\mathbb{E}[I_l]=(1-(1-p_k)^n)(1-(1-p_l)^n)$,
$$\mathrm{Cov}(I_k,I_l)=(1-p_k-p_l)^n-\big((1-p_k)(1-p_l)\big)^n\le 0,$$
because $(1-p_k)(1-p_l)=1-p_k-p_l+p_kp_l\ge 1-p_k-p_l$. Hence
$$\mathrm{Var}(Z)=\sum_{k\ge 1}(1-(1-p_k)^n)(1-p_k)^n+\sum_{k\ne l}\Big[(1-p_k-p_l)^n-\big((1-p_k)(1-p_l)\big)^n\Big],$$
the second sum being nonpositive.

*Efron–Stein comparison.* Let $Z_i$ be the number of distinct values with $X_i$ deleted. Then $0\le Z-Z_i\le 1$ (deleting one observation destroys at most one distinct value), and $\sum_i(Z-Z_i)$ equals the number of values occurring exactly once, hence $\le Z$. So $Z$ is $(1,0)$-self-bounding and Efron–Stein gives $\mathrm{Var}(Z)\le\mathbb{E}[Z]=\sum_k(1-(1-p_k)^n)$. The explicit formula refines this: $\mathrm{Var}(Z)\le\sum_k\mathrm{Var}(I_k)\le\mathbb{E}[Z]$, with strict inequality whenever some covariance is nonzero — the Efron–Stein bound does not exploit the negative dependence between distinct values. ∎
