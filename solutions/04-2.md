**Central idea.** Build a prefix code (hence uniquely decodable) greedily: process lengths in nondecreasing order, and at each step pick a codeword of the required length avoiding all extensions of previously chosen codewords. The Kraft condition guarantees an unblocked string exists, because prior codewords of length $\le \ell$ block at most $D^{\ell}(1 - D^{-\ell}) < D^{\ell}$ of the $D^{\ell}$ candidates. For the entropy bound, the Shannon lengths $\lceil -\log_D p(x)\rceil$ satisfy Kraft's inequality since $D^{-\lceil-\log_D p(x)\rceil} \le p(x)$, and rounding up costs at most $1$ bit per symbol on average.

**Solution.** Let $D = |\mathcal{Y}|$ and order $\mathcal{X} = \{x_1, x_2, \dots\}$ so that $\ell_1 \le \ell_2 \le \cdots$, where $\ell_j = \ell(x_j)$. We choose codewords $c_j$ of length $\ell_j$ inductively so that no $c_j$ is an extension of (or equal to) any earlier $c_i$.

Suppose $c_1,\dots,c_{j-1}$ chosen, all of length $\le \ell_j$. A previous codeword $c_i$ blocks exactly $D^{\ell_j - \ell_i}$ strings of length $\ell_j$ (its extensions, including itself). The total number of blocked length-$\ell_j$ strings is at most
$$\sum_{i<j} D^{\ell_j - \ell_i} = D^{\ell_j}\sum_{i<j} D^{-\ell_i} \le D^{\ell_j}\left(1 - D^{-\ell_j}\right) < D^{\ell_j},$$
using $\sum_{i\le j} D^{-\ell_i} \le 1$. Hence some length-$\ell_j$ string is unblocked; choose it as $c_j$. Since earlier codewords are no longer than $c_j$, none is a proper extension of $c_j$, and $c_j$ is not an extension of any earlier one by construction — so $\{c_j\}$ is a prefix code, hence uniquely decodable, with $|\phi(x_j)| = \ell_j$.

For the second claim, let $\ell(x) = \lceil -\log_D p(x)\rceil$ for $p(x) > 0$ (symbols with $p(x) = 0$ need no codeword). Then $D^{-\ell(x)} \le D^{\log_D p(x)} = p(x)$, so $\sum_x D^{-\ell(x)} \le \sum_x p(x) = 1$. The construction above yields $\phi$ with $|\phi(x)| = \ell(x)$, and
$$\mathbb{E}\,|\phi(X)| = \sum_x p(x)\,\lceil -\log_D p(x)\rceil \le \sum_x p(x)\big(-\log_D p(x) + 1\big) = \frac{H(X)}{\log D} + 1,$$
since $\lceil u\rceil \le u + 1$. ∎
