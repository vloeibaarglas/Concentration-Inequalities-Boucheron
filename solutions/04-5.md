**Central idea.** The set $A^* = \{P \ge Q\}$ maximizes $P(A) - Q(A)$ because every point outside it contributes negatively; the $\ell^1$ identity follows since $P - Q$ sums to zero, so the positive and negative parts have equal mass. For the coupling characterization, any coupling has $\mathbb{P}\{X \ne Y\} \ge V(P,Q)$ (restrict to $\{X \in A, Y \notin A\}$), and equality is attained by the maximal coupling: with probability $r = \sum_x \min(P(x),Q(x)) = 1 - V(P,Q)$ set $X = Y \sim R/r$ where $R = \min(P,Q)$, otherwise draw $X, Y$ independently from the disjointly supported remainders $P - R$ and $Q - R$, forcing $X \ne Y$ there.

**Solution.** Recall $V(P,Q) = \sup_A \big(P(A) - Q(A)\big)$.

*Scheffé's identity.* For any $A \subseteq \mathcal{X}$,
$$P(A) - Q(A) = \sum_{x \in A}\big(P(x) - Q(x)\big) \le \sum_{x \in A^*}\big(P(x) - Q(x)\big) = P(A^*) - Q(A^*),$$
since terms with $x \notin A^*$ are strictly negative and can only decrease the sum. Hence $V(P,Q) = P(A^*) - Q(A^*)$. Moreover, as $\sum_x (P(x) - Q(x)) = 0$,
$$\sum_{x \in A^*}\big(P(x) - Q(x)\big) = -\sum_{x \notin A^*}\big(P(x) - Q(x)\big) = \sum_{x \notin A^*}\big(Q(x) - P(x)\big),$$
so
$$\sum_x |P(x) - Q(x)| = \sum_{x \in A^*}\big(P(x)-Q(x)\big) + \sum_{x \notin A^*}\big(Q(x)-P(x)\big) = 2\big(P(A^*) - Q(A^*)\big),$$
i.e. $V(P,Q) = \frac12\sum_x |P(x) - Q(x)|$.

*Coupling lower bound.* Let $(X,Y)$ have marginals $P, Q$. For any $A$,
$$P(A) - Q(A) = \mathbb{P}\{X \in A\} - \mathbb{P}\{Y \in A\} \le \mathbb{P}\{X \in A,\ Y \notin A\} \le \mathbb{P}\{X \ne Y\}.$$
Taking $\sup_A$ gives $V(P,Q) \le \mathbb{P}\{X \ne Y\}$ for every coupling.

*Maximal coupling.* Set $R(x) = \min(P(x), Q(x))$ and $r = \sum_x R(x)$. Since $\min(p,q) = \frac12(p + q - |p-q|)$,
$$r = \tfrac12\sum_x\big(P(x) + Q(x) - |P(x)-Q(x)|\big) = 1 - V(P,Q).$$
If $r = 1$ then $P = Q$ and $X = Y \sim P$ gives $\mathbb{P}\{X \ne Y\} = 0 = V$. Assume $r < 1$. Note $P - R$ is supported on $\{P > Q\}$ and $Q - R$ on $\{P < Q\}$ (where $P = Q$, both vanish), so these supports are disjoint. Define the coupling: with probability $r$, draw $Z \sim R/r$ and set $X = Y = Z$; with probability $1 - r$, draw $X \sim (P-R)/(1-r)$ and $Y \sim (Q-R)/(1-r)$ independently. Then $X \sim r\cdot\frac{R}{r} + (1-r)\cdot\frac{P-R}{1-r} = P$, and similarly $Y \sim Q$. On the second branch $X \ne Y$ a.s. by disjoint supports, so $\mathbb{P}\{X \ne Y\} = 1 - r = V(P,Q)$. Hence $\min \mathbb{P}\{X \ne Y\} = V(P,Q)$. ∎
