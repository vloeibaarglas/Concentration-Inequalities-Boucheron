**Central idea.** As stated this is false: if $W$ is unitary and $H$ Hermitian, $WH$ need not be Hermitian, so it cannot be GUE-distributed. The correct statement is invariance under unitary *conjugation* $H\mapsto WHW^*$. This follows because the GUE density is proportional to $\exp(-\mathrm{Tr}(H^2)/2$, and both the trace of $H^2$ and Lebesgue measure on Hermitian matrices are preserved by $H\mapsto WHW^*$.

**Solution.** *Remark on the statement.* The claim that $WH$ is GUE-distributed cannot hold literally: the GUE is supported on Hermitian matrices, but $WH$ is Hermitian only if $WH = HW^*$. For example, with $W = \left(\begin{smallmatrix}0&1\\1&0\end{smallmatrix}\right)$ (unitary) and $H = \left(\begin{smallmatrix}1&0\\0&2\end{smallmatrix}\right)$ (Hermitian), $WH = \left(\begin{smallmatrix}0&2\\1&0\end{smallmatrix}\right)$ is not Hermitian. The intended statement is invariance under unitary conjugation: $WHW^*$ is GUE whenever $H$ is.

Let $H$ be GUE: $H = H^*$, with independent $H_{ii}\sim N(0,1)$ real and $H_{ij} = (X_{ij}+iY_{ij})/\sqrt2$, $X_{ij},Y_{ij}$ iid $N(0,1)$, for $i<j$. Since $\mathrm{Tr}(H^2) = \sum_i H_{ii}^2 + 2\sum_{i<j}|H_{ij}|^2$, the density of $H$ with respect to Lebesgue measure $dH$ on the real vector space of Hermitian matrices is
$$p(H) = Z^{-1}\exp\!\left(-\tfrac12\mathrm{Tr}(H^2)\right)$$
for a normalizing constant $Z$.

Fix $W\in\mathcal{U}_n$ and consider $\Phi(H) = WHW^*$, a real-linear map on Hermitian matrices. It preserves the Hilbert–Schmidt inner product: $\mathrm{Tr}(\Phi(H_1)\Phi(H_2)) = \mathrm{Tr}(WH_1W^*WH_2W^*) = \mathrm{Tr}(H_1H_2)$. Hence $\Phi$ is an orthogonal transformation, so it preserves Lebesgue measure: $d(\Phi(H)) = dH$. Moreover $\mathrm{Tr}(\Phi(H)^2) = \mathrm{Tr}(H^2)$, so $p(\Phi(H)) = p(H)$.

For any bounded Borel test function $\varphi$ on Hermitian matrices, with the change of variables $K = \Phi(H)$,
$$\mathbb{E}[\varphi(WHW^*)] = \int \varphi(\Phi(H))p(H)\,dH = \int \varphi(K)p(\Phi^{-1}(K))\,dK = \int \varphi(K)p(K)\,dK = \mathbb{E}[\varphi(H)],$$
since $\Phi^{-1} = \Phi_{W^*}$ also preserves $\mathrm{Tr}(K^2)$. Thus $WHW^*\stackrel{d}{=}H$: the GUE is invariant under unitary conjugation. ∎
