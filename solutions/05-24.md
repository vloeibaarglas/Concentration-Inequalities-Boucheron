**Central idea.** As stated this is false: for the nonzero constant polynomial $p\equiv1$, $\{x:p(x)=1\} = \mathbb{R}^n$ has infinite measure. The correct statement is that $\{q=0\}$ has measure zero for every *nonzero* polynomial $q$ (applied with $q = p-1$, this covers all $p\not\equiv1$). The proof is induction on $n$: write $q$ as a polynomial in $x_n$ with polynomial coefficients in $x'=(x_1,\dots,x_{n-1})$; where the leading coefficient vanishes use the induction hypothesis, and elsewhere each fiber has finitely many roots.

**Solution.** *Remark on the statement.* If $p\equiv1$ then $\{x\in\mathbb{R}^n:p(x)=1\} = \mathbb{R}^n$, which does not have Lebesgue measure $0$. We prove the corrected claim: if $q$ is a nonzero $n$-variate (real) polynomial, then $\{x\in\mathbb{R}^n:q(x)=0\}$ has Lebesgue measure $0$. For the original problem this gives the conclusion whenever $p-1$ is nonzero, i.e. $p\not\equiv1$.

We argue by induction on $n$, using Tonelli's theorem (zero sets of polynomials are closed, hence measurable). For $n=1$, a nonzero univariate polynomial has finitely many roots, so $\{q=0\}$ is finite and has measure $0$.

Let $n\ge2$ and write
$$q(x',x_n) = \sum_{k=0}^d q_k(x')\,x_n^k, \qquad x'=(x_1,\dots,x_{n-1}),$$
with $q_k$ $(n-1)$-variate polynomials and $q_d\not\equiv0$. Split $\{q=0\} = A\cup B$ where
$$A = \{x':q_d(x')=0\}\times\mathbb{R}, \qquad B = \{(x',x_n):q_d(x')\ne0,\ q(x',x_n)=0\}.$$
By the induction hypothesis, $N:=\{x':q_d(x')=0\}\subset\mathbb{R}^{n-1}$ has $(n-1)$-dimensional measure $0$. The $x'$-section of $A$ is $\mathbb{R}$ on $N$ and $\emptyset$ elsewhere, so by Tonelli $\lambda_n(A) = \int_N \infty\,dx' = 0$ (the integral over a null set is $0$).

For $x'$ with $q_d(x')\ne0$, the univariate polynomial $x_n\mapsto q(x',x_n)$ is nonzero of degree at most $d$, hence has at most $d$ real roots; the $x'$-section $B_{x'}$ is finite, so $\lambda_1(B_{x'}) = 0$. By Tonelli, $\lambda_n(B) = \int_{\mathbb{R}^{n-1}}\lambda_1(B_{x'})\,dx' = 0$.

Thus $\lambda_n(\{q=0\}) = 0$, completing the induction. ∎
