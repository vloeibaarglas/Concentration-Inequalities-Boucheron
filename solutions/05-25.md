**Central idea.** If $r$ is a common (possibly complex) root of $P$ and $Q$, the vector $v=(r^{m+n-1},\dots,r,1)^T$ is annihilated by every row of the Sylvester matrix, since each row encodes the coefficients of $x^kP(x)$ or $x^\ell Q(x)$ evaluated at $r$. Hence $\det S_{P,Q}=0$. A multiple root of $P$ is a common root of $P$ and $P'$. For a matrix $A$, a repeated eigenvalue is a multiple root of its characteristic polynomial $\chi_A$, so $\mathcal{P}(A)=\det S_{\chi_A,\chi_A'}$ — a polynomial in the $n^2$ entries of $A$ — vanishes exactly in that case.

**Solution.** Let $P(x)=\sum_{i=0}^m a_ix^i$ ($a_m\ne0$), $Q(x)=\sum_{j=0}^n b_jx^j$ ($b_n\ne0$). (The matrix as displayed has $n$ rows built from the $a_i$'s and $m$ rows from the $b_j$'s — i.e. $n-1$ and $m-1$ *further* shifts beyond the first row of each block — for a total of $m+n$ rows.)

*Common root $\Rightarrow$ vanishing discriminant.* Let $r\in\mathbb{C}$ with $P(r)=Q(r)=0$ and put $v=(r^{m+n-1},r^{m+n-2},\dots,r,1)^T\ne0$. Row $k$ ($1\le k\le n$) of the $a$-block is $(0,\dots,0,a_m,\dots,a_0,0,\dots,0)$ with $a_m$ in column $k$; dotting with $v$,
$$\sum_{j=0}^{m}a_{\,m-j}\,r^{\,m+n-k-j} = r^{\,n-k}\sum_{i=0}^{m}a_ir^i = r^{\,n-k}P(r) = 0.$$
Similarly row $\ell$ ($1\le\ell\le m$) of the $b$-block, with $b_n$ in column $\ell$, dots with $v$ to give $r^{\,m-\ell}Q(r)=0$. Thus $S_{P,Q}v=0$ with $v\ne0$, so $D(P,Q)=\det S_{P,Q}=0$.

*Multiple roots.* If $r$ is a multiple root of $P$, i.e. $P(x)=(x-r)^kR(x)$ with $k\ge2$, then $P(r)=P'(r)=0$. By the first part applied to $P,P'$, $D(P,P')=0$.

*Detecting repeated eigenvalues.* Let $A=(a_{ij})$ be $n\times n$ and $\chi_A(t)=\det(tI-A)=t^n+c_{n-1}(A)t^{n-1}+\cdots+c_0(A)$ its characteristic polynomial; each $c_k$ is a (fixed, integer-coefficient) polynomial in the $n^2$ entries $a_{ij}$. Set
$$\mathcal{P}(a_{11},\dots,a_{nn}) = D(\chi_A,\chi_A') = \det S_{\chi_A,\chi_A'}.$$
Since the entries of $S_{\chi_A,\chi_A'}$ are among the $c_k(A)$ (and $0$'s and the integers $n,n-1,\dots$ from differentiating), and the determinant is a polynomial in the matrix entries, $\mathcal{P}$ is an $n^2$-variate polynomial in the entries of $A$. If $A$ has an eigenvalue of multiplicity $>1$, then $\chi_A$ has a multiple (complex) root, so $\mathcal{P}(A)=0$ by the second part. (For $n=1$, $\mathcal{P}\equiv1$, consistent with $1\times1$ matrices having no repeated eigenvalue; e.g. on diagonal matrices with distinct entries $\mathcal{P}\ne0$, so $\mathcal{P}$ is not identically zero for $n\ge2$.) ∎
