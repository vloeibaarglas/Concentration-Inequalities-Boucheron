**Central idea.** All identities come from differentiating $H = U\Lambda U^*$ (with $U^*U = I$ and $\Lambda = \mathrm{diag}(\lambda_1,\ldots,\lambda_n)$ independent of the $p_\ell$): unitarity forces $S_\ell$ skew-Hermitian, the product rule gives $B_\ell$ as a commutator, and $\partial H/\partial\lambda_i = u_iu_i^*$ because only the $i$-th eigenvalue moves.

**Solution.** Write $\Lambda = \mathrm{diag}(\lambda_1,\ldots,\lambda_n)$ and $H = U\Lambda U^*$, where $U$ depends on $p = (p_1,\ldots,p_{n(n-1)})$ but not on $\Lambda$.

$S_\ell$ is skew-Hermitian. Differentiating $U^*U = I$ with respect to $p_\ell$,
$$0 = \frac{\partial U^*}{\partial p_\ell}U + U^*\frac{\partial U}{\partial p_\ell} = S_\ell^* + S_\ell,$$
so $S_\ell^* = -S_\ell$.

The commutator formula. Since $\Lambda$ is independent of $p_\ell$,
$$\frac{\partial H}{\partial p_\ell} = \frac{\partial U}{\partial p_\ell}\Lambda U^* + U\Lambda\frac{\partial U^*}{\partial p_\ell}.$$
Conjugating by $U$,
$$U^*\frac{\partial H}{\partial p_\ell}U = U^*\frac{\partial U}{\partial p_\ell}\Lambda + \Lambda\frac{\partial U^*}{\partial p_\ell}U = S_\ell\Lambda + \Lambda S_\ell^* = S_\ell\Lambda - \Lambda S_\ell,$$
using $S_\ell^* = -S_\ell$. Entry-wise, $(S_\ell\Lambda)[i,j] = S_\ell[i,j]\lambda_j$ and $(\Lambda S_\ell)[i,j] = \lambda_i S_\ell[i,j]$, so with $B_\ell = U^*\frac{\partial H}{\partial p_\ell}U$,
$$B_\ell[i,j] = S_\ell[i,j](\lambda_j-\lambda_i), \tag{5.7}$$
for all $i,j$.

Derivative in $\lambda_i$. Write $H = \sum_{k=1}^n \lambda_k u_ku_k^*$ where $u_k$ is the $k$-th column of $U$. Since $U$ is independent of $\Lambda$,
$$\frac{\partial H}{\partial\lambda_i} = u_iu_i^*.$$
This is the orthogonal projection onto $\mathrm{span}(u_i)$: $(u_iu_i^*)^* = u_iu_i^*$ and $(u_iu_i^*)^2 = u_i(u_i^*u_i)u_i^* = u_iu_i^*$ as $u_i^*u_i = 1$.

Conjugating by $U$: since $u_i$ is the $i$-th column of $U$, $U^*u_i = e_i$, so
$$U^*\frac{\partial H}{\partial\lambda_i}U = (U^*u_i)(u_i^*U) = e_ie_i^* = \mathrm{diag}(\underbrace{0,\ldots,0}_{i-1},1,\underbrace{0,\ldots,0}_{n-i}).$$
Entry-wise, $(U^*AU)[j,k] = \sum_{j',k'}\bar{U}[j',j]\,A[j',k']\,U[k',k]$ for any $A$, so with $A = \partial H/\partial\lambda_i$,
$$\left(U^*\frac{\partial H}{\partial\lambda_i}U\right)[j,k] = \sum_{j'=1}^n\sum_{k'=1}^n \frac{\partial H}{\partial\lambda_i}[j',k']\,\bar{U}[j',j]\,U[k',k] = \mathbb{1}_{\{i=j=k\}}, \tag{5.8}$$
for $1 \le j,k \le n$. ∎
