**Central idea.** A logarithmic Sobolev inequality with constant $c$ linearizes (as in Exercise 5.2) to a Poincar\'e inequality with constant $c/2$. But Poincar\'e with constant $1$ is best possible: the dictator $f(x) = x_1$ satisfies $\mathrm{Var}(f) = \mathcal{E}(f) = 1$. Hence $c/2 \ge 1$, so no $c < 2$ can work in Theorem 5.1.

**Solution.** Suppose, to the contrary, that $\mathrm{Ent}(g^2) \le c\,\mathcal{E}(g)$ held for all $g:\{-1,1\}^n \to \mathbb{R}$ with some $c < 2$. Applying this to $g = 1+\varepsilon f$ and using $\mathrm{Ent}((1+\varepsilon f)^2) = 2\varepsilon^2\mathrm{Var}(f)+O(\varepsilon^3)$ (Exercise 5.2) together with $\mathcal{E}(1+\varepsilon f) = \varepsilon^2\mathcal{E}(f)$ gives
$$2\varepsilon^2\mathrm{Var}(f)+O(\varepsilon^3) \le c\,\varepsilon^2\mathcal{E}(f) \qquad \forall\,f,$$
whence, dividing by $\varepsilon^2$ and letting $\varepsilon \to 0$,
$$\mathrm{Var}(f) \le \frac{c}{2}\,\mathcal{E}(f) \qquad \forall\,f.$$
Take the dictator $f(x) = x_1$. Then $\mathbb{E}[f(X)] = 0$ and $\mathbb{E}[f(X)^2] = 1$, so $\mathrm{Var}(f) = 1$. Moreover, flipping coordinate $1$ changes $f$ by $2X_1$ while flipping any other coordinate leaves $f$ unchanged, so with the usual Dirichlet form $\mathcal{E}(f) = \frac14\sum_{i=1}^n\mathbb{E}[(f(X)-f(X^{(i)}))^2] = \frac14\mathbb{E}[(2X_1)^2] = 1$. Thus $1 = \mathrm{Var}(f) \le \frac{c}{2}\mathcal{E}(f) = \frac{c}{2}$, forcing $c \ge 2$, a contradiction. Hence the constant $2$ in Theorem 5.1 cannot be improved. ∎
