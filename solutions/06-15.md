**Central idea.** Plant a clique: fix a set $S$ of $m = \lceil Knp\rceil$ vertices with $K$ a large constant depending on $a$. With probability $p^{\binom{m}{2}} = \exp(-\binom{m}{2}\log(1/p)) \ge \exp(-cp^2n^2\log(1/p))$ the set $S$ induces a clique, contributing $\binom{m}{3} \ge (Knp-2)^3/6$ triangles; choosing $K$ so that $(K-2)^3 > 1+6a$ makes this exceed $\mathbb{E}Z+an^3p^3$. The hypothesis $p \ge 1/n$ must be supplemented with $p$ bounded away from $1$: at $p = 1$ the left side is $0$ while the right side is $1$, so the inequality is false without an upper bound on $p$.

**Solution.** Let $Z$ be the number of triangles, so $\mathbb{E}Z = \binom{n}{3}p^3 \le n^3p^3/6$. Fix $a > 0$ and choose an integer $K \ge 4$ with $(K-2)^3 \ge 1+6a$ (e.g.\ $K = 3+\lceil(1+6a)^{1/3}\rceil$); $K$ depends only on $a$. Assume $1/n \le p \le 1/(2K)$, so that $m := \lceil Knp\rceil \le n$ and $m \ge Knp \ge K \ge 4$.

Fix any set $S$ of $m$ vertices. On the event $C_S = \{S\text{ induces a clique}\}$ every triple in $S$ is a triangle, so
$$Z \ge \binom{m}{3} \ge \frac{(m-2)^3}{6} \ge \frac{(Knp-2)^3}{6}.$$
Since $np \ge 1$, $Knp-2 \ge (K-2)np$, and therefore
$$Z \ge \frac{(K-2)^3}{6}\,n^3p^3 \ge \frac{1+6a}{6}\,n^3p^3 = \frac{n^3p^3}{6} + an^3p^3 \ge \mathbb{E}Z + an^3p^3 \quad\text{on }C_S,$$
using $\mathbb{E}Z = \binom{n}{3}p^3 < n^3p^3/6$ for the strict inequality $Z > \mathbb{E}Z+an^3p^3$. Hence
$$\mathbb{P}\{Z > \mathbb{E}Z+an^3p^3\} \ge \mathbb{P}(C_S) = p^{\binom{m}{2}} = \exp\!\left(-\binom{m}{2}\log\frac1p\right).$$
Now $\binom{m}{2} \le m^2/2 \le (Knp+1)^2/2 \le K^2n^2p^2+1 \le (K^2+1)n^2p^2$, using $(x+1)^2 \le 2x^2+2$ and $n^2p^2 \ge 1$. Thus
$$\mathbb{P}\{Z > \mathbb{E}Z+an^3p^3\} \ge \exp\!\big(-c\,p^2n^2\log(1/p)\big), \qquad c = K^2+1,$$
with $c$ depending only on $a$ (through $K$).

*Remark on the range of $p$.* The hypothesis $p \ge 1/n$ alone does not suffice: $p$ must also be bounded away from $1$. Indeed, at $p = 1$ we have $Z = \binom{n}{3} = \mathbb{E}Z$ a.s., so the left-hand side is $\mathbb{P}\{Z > \binom{n}{3}+an^3\} = 0$, while the right-hand side is $\exp(-c\cdot n^2\cdot\log 1) = 1$ — the inequality $0 \ge 1$ is false. More generally, if $\binom{n}{3} \le \binom{n}{3}p^3+an^3p^3$ (which holds for $p$ sufficiently close to $1$), the event $\{Z > \mathbb{E}Z+an^3p^3\}$ is empty while the right-hand side is strictly positive. The planted-clique heuristic is a small-$p$ argument; the proof above covers $1/n \le p \le 1/(2K)$. ∎
