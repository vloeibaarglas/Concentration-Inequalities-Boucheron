**Central idea.** This is the $g(X)$-version of Theorem 6.27. For $\lambda < 0$, the third inequality of Theorem 6.15 (symmetrized modified log-Sobolev) bounds the Herbst deficit $\lambda\psi'(\lambda) - \psi(\lambda)$ by $\lambda^2\mathbb{E}[e^{\lambda Z}V^-]/\mathbb{E}[e^{\lambda Z}]$ where $V^- = \sum_i((Z'_i-Z)_+)^2 \le g(X)$, using $\tau(x) \le x^2$ for $x \le 0$. Since $\lambda < 0$ and $f$ is nondecreasing, $e^{\lambda Z}$ is nonincreasing while $g$ is nondecreasing, so Harris's inequality (Theorem 2.15) decouples $\mathbb{E}[e^{\lambda Z}g(X)] \le \mathbb{E}[e^{\lambda Z}]\mathbb{E}[g(X)]$. The Herbst argument then gives $\psi(\lambda) \le \lambda^2\mathbb{E}[g(X)]$ and Chernoff yields the lower tail.

**Solution.** Let $X'_i$ be an independent copy of $X_i$ and $Z'_i = f(X_1,\ldots,X'_i,\ldots,X_n)$. Put $V^- = \sum_{i=1}^n ((Z'_i - Z)_+)^2 = \sum_{i=1}^n ((Z - Z'_i)_-)^2 \le g(X)$ a.s. Assume $0 < \mathbb{E}[g(X)] < \infty$ (if $\mathbb{E}[g(X)] = \infty$ the bound is trivially $1$; the degenerate case $\mathbb{E}[g(X)] = 0$ is excluded). Write $F(\lambda) = \mathbb{E}[e^{\lambda Z}]$ and $\psi(\lambda) = \log \mathbb{E}[e^{\lambda(Z-\mathbb{E}Z)}] = \log F(\lambda) - \lambda\mathbb{E}Z$, so that $\lambda\psi'(\lambda) - \psi(\lambda) = \lambda F'(\lambda)/F(\lambda) - \log F(\lambda)$.

For $\lambda < 0$, the third inequality of Theorem 6.15 gives, with $\tau(x) = x(e^x-1)$,
$$\lambda\frac{F'(\lambda)}{F(\lambda)} - \log F(\lambda) \le \frac{1}{F(\lambda)}\sum_{i=1}^n \mathbb{E}\big[e^{\lambda Z}\,\tau(\lambda(Z'_i - Z)_+)\big].$$
Since $\lambda < 0$ and $(Z'_i-Z)_+ \ge 0$, we have $\lambda(Z'_i-Z)_+ \le 0$. For $x \le 0$, writing $x = -y$ with $y \ge 0$, $\tau(x) = \tau(-y) = y(1-e^{-y}) \le y^2 = x^2$ (using $1 - e^{-y} \le y$). Hence $\tau(\lambda(Z'_i-Z)_+) \le \lambda^2((Z'_i-Z)_+)^2$, and
$$\lambda\psi'(\lambda) - \psi(\lambda) \le \lambda^2\,\frac{\mathbb{E}[e^{\lambda Z} V^-]}{F(\lambda)} \le \lambda^2\,\frac{\mathbb{E}[e^{\lambda Z} g(X)]}{F(\lambda)}, \qquad \lambda < 0.$$
Because $f$ is nondecreasing in each variable, $Z = f(X)$ is nondecreasing in $X$, so for $\lambda < 0$ the function $X \mapsto e^{\lambda Z}$ is nonincreasing, while $X \mapsto g(X)$ is nondecreasing by hypothesis. Harris's inequality (Theorem 2.15, opposite-monotonicity case) gives $\mathbb{E}[e^{\lambda Z}g(X)] \le \mathbb{E}[e^{\lambda Z}]\,\mathbb{E}[g(X)]$. Therefore
$$\lambda\psi'(\lambda) - \psi(\lambda) \le \lambda^2\,\mathbb{E}[g(X)], \qquad \lambda < 0.$$
This is the Herbst differential inequality: $\frac{d}{d\lambda}[\psi(\lambda)/\lambda] = (\lambda\psi'(\lambda)-\psi(\lambda))/\lambda^2 \le \mathbb{E}[g(X)]$. Integrating from $\lambda < 0$ to $0$ and using $\psi(\lambda)/\lambda \to \psi'(0) = 0$ gives $-\psi(\lambda)/\lambda \le -\lambda\,\mathbb{E}[g(X)]$, i.e.
$$\psi(\lambda) \le \lambda^2\,\mathbb{E}[g(X)], \qquad \lambda < 0.$$
Finally, Chernoff's bound for the lower tail: for $\lambda < 0$ and $t > 0$,
$$\mathbb{P}\{Z - \mathbb{E}Z \le -t\} = \mathbb{P}\{e^{\lambda(Z-\mathbb{E}Z)} \ge e^{-\lambda t}\} \le e^{\lambda t + \psi(\lambda)} \le \exp\big(\lambda t + \lambda^2\mathbb{E}[g(X)]\big).$$
Minimizing over $\lambda < 0$ at $\lambda = -t/(2\mathbb{E}[g(X)])$ yields
$$\mathbb{P}\{Z < \mathbb{E}Z - t\} \le \exp\!\left(\frac{-t^2}{4\,\mathbb{E}[g(X)]}\right), \qquad t > 0.$$
∎
