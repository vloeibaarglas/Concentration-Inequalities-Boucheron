**Central idea.** Write $A_0, A_1 \subset Q = \{-1,1\}^{n-1}$ for the two $i$-sections and $S_a, S_b$ for the simplicial initial segments replacing them ($a = |A_0|$, $b = |A_1|$). The vertex boundary splits into within-face and across-face parts, giving the exact formula $|\partial_V(A)| = |\partial_V(A_0)| + |\partial_V(A_1)| + |A_1 \setminus N[A_0]| + |A_0 \setminus N[A_1]|$ where $N[X] = X \cup \partial_V(X)$. Arguing by induction on $n$ (so Harper's inequality is available in dimension $n-1$), the within-face terms do not increase under compression. The leftover "far" term $|S_b \setminus N[S_a]|$ is controlled by the nested-neighborhoods property of the simplicial ordering ($N[S_k]$ is always an initial segment) via a short counting argument.

**Solution.** We prove by induction on $n$ that $|\partial_V(C_i(A))| \le |\partial_V(A)|$ for all $A \subset \{-1,1\}^n$ and all $i$. For $n = 1$ the sections are singletons or empty, hence already initial segments, so $C_i(A) = A$. Assume Harper's vertex isoperimetric inequality in dimension $n-1$: $|\partial_V(X)| \ge |\partial_V(S_{|X|})|$ for $X \subset \{-1,1\}^{n-1}$.

By symmetry take $i = n$. Write $Q = \{-1,1\}^{n-1}$ and
$$A_0 = \{y \in Q : (y,-1) \in A\}, \qquad A_1 = \{y \in Q : (y,+1) \in A\},$$
so $A = (A_0 \times \{-1\}) \cup (A_1 \times \{+1\})$. (The problem statement has two typos: in $A^{(i+)}$ it should be $x^{(i,1)} \in A$, and "$i$-th component is $0$ (and $1$)" should be $-1$ (and $+1$).) Put $a = |A_0|$, $b = |A_1|$, and let $S_a, S_b \subset Q$ be the simplicial initial segments. Swapping the two faces if necessary (an automorphism preserving $|\partial_V|$), assume $a \le b$, so $S_a \subseteq S_b$. Then $C_n(A) = (S_a \times \{-1\}) \cup (S_b \times \{+1\})$.

For $X \subset Q$ let $N[X] = X \cup \partial_V(X)$ be the closed vertex-neighborhood in $Q$.

*Boundary decomposition.* A point $(y,-1) \notin A$ lies in $\partial_V(A)$ iff $y \in \partial_V(A_0)$ or $y \in A_1$. Hence, with $L_A$ the lower-face part of $\partial_V(A)$,
$$L_A = \{y \notin A_0 : y \in \partial_V(A_0) \text{ or } y \in A_1\} = \partial_V(A_0) \;\dot\cup\; (A_1 \setminus N[A_0]),$$
disjoint because $\partial_V(A_0) \subseteq N[A_0]$. Indeed, if $y \in L_A$ and $y \notin \partial_V(A_0)$ then $y \in A_1 \setminus A_0$ and $y \notin \partial_V(A_0)$, so $y \notin N[A_0]$. Thus $|L_A| = |\partial_V(A_0)| + |A_1 \setminus N[A_0]|$, and similarly for the upper face. Therefore
$$|\partial_V(A)| = |\partial_V(A_0)| + |\partial_V(A_1)| + |A_1 \setminus N[A_0]| + |A_0 \setminus N[A_1]|. \tag{1}$$
For $C = C_n(A)$, the same argument gives $|L_C| = |\partial_V(S_a)| + |S_b \setminus N[S_a]|$ and $|U_C| = |\partial_V(S_b)| + |S_a \setminus N[S_b]|$. Since $S_a \subseteq S_b \subseteq N[S_b]$, the last term vanishes:
$$|\partial_V(C)| = |\partial_V(S_a)| + |\partial_V(S_b)| + |S_b \setminus N[S_a]|. \tag{2}$$

*Induction.* By the inductive hypothesis, $|\partial_V(A_0)| \ge |\partial_V(S_a)|$ and $|\partial_V(A_1)| \ge |\partial_V(S_b)|$. From (1)--(2) it suffices to prove
$$|S_b \setminus N[S_a]| \le \delta_0 + \delta_1 + |A_1 \setminus N[A_0]| + |A_0 \setminus N[A_1]|, \tag{3}$$
where $\delta_0 = |\partial_V(A_0)| - |\partial_V(S_a)| \ge 0$ and $\delta_1 = |\partial_V(A_1)| - |\partial_V(S_b)| \ge 0$.

*Nested neighborhoods.* The simplicial ordering has the property that $N[S_k]$ is an initial segment for every $k$ (the ordering sorts by Hamming weight, then reverse-lexicographically; a direct check shows the closed neighborhood of an initial segment is again initial). Write $N[S_a] = S_{a'}$. Then $|S_b \setminus N[S_a]| = \max(0, b - a')$, and $|\partial_V(S_a)| = a' - a$.

*Proof of (3).* If $b \le a'$ the left side is $0$. Assume $b > a'$, so the left side equals $b - a'$. Since $|A_1 \setminus N[A_0]| = b - |A_1 \cap N[A_0]|$, (3) becomes, after cancelling $b$,
$$|A_1 \cap N[A_0]| \le a' + \delta_0 + \delta_1 + |A_0 \setminus N[A_1]|. \tag{4}$$
But $|A_1 \cap N[A_0]| \le |N[A_0]| = a + |\partial_V(A_0)| = a + |\partial_V(S_a)| + \delta_0 = a' + \delta_0$, using $|\partial_V(S_a)| = a' - a$. Since $\delta_1 + |A_0 \setminus N[A_1]| \ge 0$, (4) follows. This proves (3).

Finally, from (1), (2), the inductive bounds, and (3):
\begin{align*}
|\partial_V(A)| - |\partial_V(C)|
&= \delta_0 + \delta_1 + |A_1 \setminus N[A_0]| + |A_0 \setminus N[A_1]| - |S_b \setminus N[S_a]| \\
&\ge 0,
\end{align*}
so $|\partial_V(C_i(A))| \le |\partial_V(A)|$. This completes the induction. ∎
