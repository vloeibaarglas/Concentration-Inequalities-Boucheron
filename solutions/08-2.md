**Central idea.** With $g = -f$, the key property reads $g(y) \le g(x) + \sum_i 2x_i\mathbb{1}_{\{x_i \ne y_i\}} + 1$. Repeating the proof of Theorem 8.6 but keeping the "$+1$" and using Marton's conditional transportation inequality (Theorem 8.5, dropping the $Y$-conditional term) gives $\mathbb{E}_{\mathbb{Q}}g - \mathbb{E}_{\mathbb{P}}g \le \sqrt{2vD(\mathbb{Q}\|\mathbb{P})} + 1$ with $v = 4\sum_i\mathbb{E}X_i^2$. Applying this to $\mathbb{Q} = \mathbb{P}(\cdot \mid \{g > \mathbb{E}g + t\})$ — the standard Lemma 4.18 deduction — turns the transportation bound into the tail bound, and $g = -f$ converts the upper tail of $g$ into the left tail of $Z$.

**Solution.** Let $\mathbb{P}$ be the distribution of $X = (X_1,\dots,X_n)$ and $\mathbb{Q} \ll \mathbb{P}$. Put $g = -f$, so the key property (Section 7.6) becomes
$$g(y) \le g(x) + \sum_{i=1}^n c_i(x)\,\mathbb{1}_{\{x_i \ne y_i\}} + 1, \qquad c_i(x) = 2x_i.$$
Let $P \in \mathcal{P}(\mathbb{P},\mathbb{Q})$ with $(X,Y) \sim P$, $X \sim \mathbb{P}$, $Y \sim \mathbb{Q}$. Then
$$\mathbb{E}_{\mathbb{Q}}g - \mathbb{E}_{\mathbb{P}}g = \mathbb{E}_P[g(Y)-g(X)] \le \mathbb{E}_P\left[\sum_{i=1}^n c_i(X)\mathbb{1}_{\{X_i \ne Y_i\}}\right] + 1.$$
Conditioning on $X$ and applying Cauchy–Schwarz twice,
\begin{align*}
\mathbb{E}_P\left[\sum_i c_i(X)\mathbb{1}_{\{X_i \ne Y_i\}}\right]
&= \mathbb{E}_{\mathbb{P}}\left[\sum_i c_i(X)\,P\{X_i \ne Y_i \mid X\}\right] \\
&\le \mathbb{E}_{\mathbb{P}}\left[\sqrt{\sum_i c_i(X)^2}\,\sqrt{\sum_i P\{X_i \ne Y_i \mid X\}^2}\right] \\
&\le \sqrt{\mathbb{E}_{\mathbb{P}}\sum_i c_i(X)^2}\,\sqrt{\mathbb{E}_P\sum_i P\{X_i \ne Y_i \mid X\}^2}.
\end{align*}
With $v = \mathbb{E}_{\mathbb{P}}\sum_i c_i(X)^2 = 4\sum_{i=1}^n \mathbb{E}X_i^2$ and Theorem 8.5 (dropping the nonnegative $Y$-conditional term, so $\min_P \mathbb{E}_P\sum_i P\{X_i \ne Y_i \mid X\}^2 \le 2D(\mathbb{Q}\|\mathbb{P})$), minimizing over $P$ gives
$$\mathbb{E}_{\mathbb{Q}}g - \mathbb{E}_{\mathbb{P}}g \le \sqrt{2v\,D(\mathbb{Q}\|\mathbb{P})} + 1 \qquad \text{for all }\mathbb{Q} \ll \mathbb{P}.$$

Now fix $t > 0$ and put $p = \mathbb{P}\{g > \mathbb{E}g + t\}$; if $p = 0$ there is nothing to prove. Take $\mathbb{Q}$ with $d\mathbb{Q}/d\mathbb{P} = \mathbb{1}_{\{g > \mathbb{E}g+t\}}/p$, so $\mathbb{Q} \ll \mathbb{P}$, $\mathbb{E}_{\mathbb{Q}}g - \mathbb{E}g \ge t$, and $D(\mathbb{Q}\|\mathbb{P}) = \log(1/p)$. The transportation bound gives
$$t \le \sqrt{2v\log\frac{1}{p}} + 1.$$
For $t > 1$ this yields $\log(1/p) \ge (t-1)^2/(2v)$, i.e.
$$\mathbb{P}\{g > \mathbb{E}g + t\} \le \exp\left(-\frac{(t-1)^2}{2v}\right), \qquad t > 1.$$
Since $g = -f$ and $Z = f(X)$, $\{g > \mathbb{E}g + t\} = \{Z < \mathbb{E}Z - t\}$, and with $v = 4\sum_i \mathbb{E}X_i^2$,
$$\mathbb{P}\{Z < \mathbb{E}Z - t\} \le \exp\left(-\frac{(t-1)^2}{8\sum_{i=1}^n \mathbb{E}X_i^2}\right), \qquad t > 1.$$
∎

**Erratum.** An earlier version of this solution stated the bound for all $t > 0$, with the parenthetical claim that it was "trivial for $t \le 1$ as the right-hand side exceeds $1$". Both are false. The right-hand side is $\exp(-(t-1)^2/(8\sum_i\mathbb{E}X_i^2)) \le 1$ for every $t$ (the exponent is nonpositive, vanishing only at $t = 1$), so it never exceeds $1$; and the inequality itself can fail for $t < 1$ (at $t = 1$ the right-hand side equals $1$, so the bound holds trivially there). Counterexample: $n = 10$, $X_i$ i.i.d.\ $\mathrm{Bernoulli}(0.01)$, $Z = \sum_{i=1}^n X_i$, which satisfies the key property (for $x_i, y_i \in \{0,1\}$, $x_i - y_i \le 2x_i\mathbf{1}_{\{x_i \ne y_i\}}$ holds termwise: $-1 \le 0$, $0 \le 0$, $1 \le 2$). Here $\mathbb{E}Z = 0.1$ and $\sum_i\mathbb{E}X_i^2 = 0.1$, and at $t = 0.05$,
$$\mathbb{P}\{Z < \mathbb{E}Z - t\} = \mathbb{P}\{Z = 0\} = 0.99^{10} \approx 0.9044 > 0.3236 \approx \exp\left(-\frac{(0.05-1)^2}{8 \cdot 0.1}\right).$$
The derivation above establishes the bound only for $t > 1$, which is the corrected statement (presumably the book's Example 8.9 as intended).
