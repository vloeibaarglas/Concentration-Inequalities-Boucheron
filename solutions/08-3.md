**Central idea.** Put $s = \sqrt{y}$, $r = \sqrt{x}$ and complete the square: $s^2 - as \le r^2$ becomes $(s-a/2)^2 \le r^2 + a^2/4$. If $s \le a/2$ the claim is immediate; else $s \le a/2 + \sqrt{r^2+a^2/4}$, and squaring plus the elementary estimate $\sqrt{r^2+a^2/4} \le r + a/2$ gives $s^2 \le r^2 + ar + a^2$.

**Solution.** Let $s = \sqrt{y} > 0$ and $r = \sqrt{x} > 0$. The hypothesis is $s^2 - as \le r^2$. Completing the square,
$$\left(s - \frac{a}{2}\right)^2 = s^2 - as + \frac{a^2}{4} \le r^2 + \frac{a^2}{4}.$$
If $s \le a/2$, then $s^2 \le a^2/4 \le r^2 + ar + a^2$ since $r^2 + ar \ge 0$. Otherwise $s > a/2$ and taking square roots gives $s - a/2 \le \sqrt{r^2 + a^2/4}$, i.e.
$$s \le \frac{a}{2} + \sqrt{r^2 + \frac{a^2}{4}}.$$
Squaring,
$$s^2 \le \frac{a^2}{4} + a\sqrt{r^2 + \frac{a^2}{4}} + r^2 + \frac{a^2}{4} = r^2 + \frac{a^2}{2} + a\sqrt{r^2 + \frac{a^2}{4}}.$$
Since $\sqrt{r^2 + a^2/4} \le r + a/2$ (both sides nonnegative; squaring gives $r^2 + a^2/4 \le r^2 + ar + a^2/4$),
$$s^2 \le r^2 + \frac{a^2}{2} + a\left(r + \frac{a}{2}\right) = r^2 + ar + a^2.$$
That is, $y \le x + a\sqrt{x} + a^2$. ∎
