**Central idea.** On the symmetric difference $A \triangle B$, the binary-valued $f$ and the thresholded indicator $\mathbb{1}_{\{g \geq 1/2\}}$ disagree, which forces $|f - g| \geq 1/2$: if $f(x) = 1$ then $g(x) < 1/2$, and if $f(x) = 0$ then $g(x) \geq 1/2$. Hence $\mathbb{1}_{A \triangle B} \leq 4(f-g)^2$ pointwise, and taking expectations gives the claim.

**Solution.** Write $A \triangle B = (A \setminus B) \cup (B \setminus A)$, where $A = \{x : f(x) = 1\}$ and $B = \{x : g(x) \geq 1/2\}$, so $A \triangle B = \{x : f(x) \neq \mathbb{1}_{\{g(x) \geq 1/2\}}\}$.

If $x \in A \setminus B$, then $f(x) = 1$ and $g(x) < 1/2$, so
$$(f(x) - g(x))^2 = (1 - g(x))^2 > \left(\tfrac12\right)^2 = \tfrac14.$$
If $x \in B \setminus A$, then $f(x) = 0$ and $g(x) \geq 1/2$, so
$$(f(x) - g(x))^2 = g(x)^2 \geq \tfrac14.$$
Thus $\mathbb{1}_{A \triangle B}(x) \leq 4(f(x) - g(x))^2$ for every $x \in \{-1,1\}^n$. Taking expectations over the uniform measure,
$$\mathbb{P}(A \triangle B) \leq 4\,\mathbb{E}\big[(f-g)^2\big]. \qquad \blacksquare$$
