**Central idea.** For binary-valued $f$, Theorem 9.9 simplifies: $\mathbb{E}[(f(X)-f(X^{(i)}))^2] = I_i(f)$ and $\|g_i\|_2/\|g_i\|_1 = 1/\sqrt{I_i(f)}$, giving $\mathrm{Var}(f) \leq C\sum_i I_i/(1+\tfrac12\log(1/I_i))$. The KKL bound $\sum_i I_i^2 \gtrsim \mathrm{Var}(f)^2\log^2 n/n$ follows by Cauchy–Schwarz and contradiction: if $\sum_i I_i^2$ were too small, every $I_i$ would be tiny, making the logarithmic denominators large and contradicting the variance lower bound.

**Solution.** Let $f : \{-1,1\}^n \to \{0,1\}$ be binary-valued. If $\mathrm{Var}(f) = 0$ there is nothing to prove; assume $\mathrm{Var}(f) > 0$. For $n = 1$ the claim is trivial since $\log 1 = 0$; assume $n \geq 2$.

For binary $f$, $(f(X)-f(X^{(i)}))^2 = \mathbb{1}_{\{f(X) \neq f(X^{(i)})\}}$, so $\mathbb{E}[(f(X)-f(X^{(i)}))^2] = I_i(f)$. Moreover, with $g_i = (f-f^{(i)})/2$, $\|g_i\|_2^2 = I_i(f)/4$ and $\|g_i\|_1 = I_i(f)/2$ (since $|f-f^{(i)}| = \mathbb{1}_{\{f \neq f^{(i)}\}}$), hence $\|g_i\|_2/\|g_i\|_1 = 1/\sqrt{I_i(f)}$ whenever $I_i(f) > 0$ (the summand is $0$ when $I_i(f) = 0$). Theorem 9.9 therefore gives, with a universal constant $C > 0$,
$$\mathrm{Var}(f) \leq C\sum_{i : I_i > 0} \frac{I_i}{1 + \tfrac12\log(1/I_i)}. \tag{*}$$

We show $\sum_i I_i^2 \geq \frac{1}{K}\frac{\mathrm{Var}(f)^2\log^2 n}{n}$ with $K = \max(64C^2, 1)$. Suppose, for contradiction,
$$\sum_i I_i^2 < \frac{\mathrm{Var}(f)^2\log^2 n}{Kn}.$$
Then $I_i < \epsilon := \frac{\mathrm{Var}(f)\log n}{\sqrt{Kn}}$ for every $i$. By Cauchy–Schwarz,
$$\left(\sum_{i:I_i>0}\frac{I_i}{1+\tfrac12\log(1/I_i)}\right)^2 \leq \left(\sum_{i:I_i>0} I_i^2\right)\left(\sum_{i:I_i>0}\frac{1}{\big(1+\tfrac12\log(1/I_i)\big)^2}\right).$$
Since $x \mapsto \big(1+\tfrac12\log(1/x)\big)^{-2}$ is increasing on $(0,\infty)$ and $I_i \leq \epsilon$,
$$\sum_{i:I_i>0}\frac{1}{\big(1+\tfrac12\log(1/I_i)\big)^2} \leq \frac{n}{\big(1+\tfrac12\log(1/\epsilon)\big)^2}.$$
Combining with $(*)$,
$$\frac{\mathrm{Var}(f)^2}{C^2} < \frac{\mathrm{Var}(f)^2\log^2 n}{Kn}\cdot\frac{n}{\big(1+\tfrac12\log(1/\epsilon)\big)^2},$$
and cancelling $\mathrm{Var}(f)^2 > 0$ gives $1+\tfrac12\log(1/\epsilon) < \frac{C\log n}{\sqrt{K}}$, i.e.
$$\log(1/\epsilon) < \frac{2C\log n}{\sqrt{K}} - 2. \tag{1}$$
On the other hand, $\epsilon = \frac{\mathrm{Var}(f)\log n}{\sqrt{Kn}}$ and $\mathrm{Var}(f) \leq 1/4$, so
$$\log(1/\epsilon) = \log\frac{\sqrt{Kn}}{\mathrm{Var}(f)\log n} \geq \log\frac{4\sqrt{Kn}}{\log n} = \tfrac12\log(Kn) - \log\log n + \log 4. \tag{2}$$
From (1)–(2), $\tfrac12\log K + \big(\tfrac12-\tfrac{2C}{\sqrt{K}}\big)\log n - \log\log n + \log 4 + 2 < 0$. Since $K \geq 64C^2$, $\tfrac{2C}{\sqrt{K}} \leq \tfrac14$, so $\tfrac12\log K + \tfrac14\log n - \log\log n + \log 4 + 2 < 0$. But $\tfrac14\log n - \log\log n \geq -0.39$ for $n \geq 2$ (minimized at $n = e^4$), $\tfrac12\log K \geq 0$, and $\log 4 + 2 > 3.38$, so the left side exceeds $3 > 0$, a contradiction.

Hence $\sum_{i=1}^n I_i(f)^2 \geq \frac{1}{K}\frac{\mathrm{Var}(f)^2\log^2 n}{n}$, which is Theorem 9.5 up to the constant factor $1/K$. In particular, $\max_i I_i(f) \geq \frac{1}{\sqrt{K}}\frac{\mathrm{Var}(f)\log n}{n}$. ∎
