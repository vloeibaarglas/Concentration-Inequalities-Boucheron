**Central idea.** Adapt the proof of Theorem 9.8 (truncation $g_{a,b}$ + Theorem 9.4) to the one-sided $(\cdot)_-$ sensitivity. The shift $a = Q_{1-\gamma}+B$ is the key: since single-coordinate changes are at most $B$, the negative part $(g_{a,b}(X)-g_{a,b}(X^{(i)}))_-$ can only be nonzero when $f(X) > Q_{1-\gamma}$, localizing both $\mathcal{E}(g_{a,b})$ and $\sum_j(\mathbb{E}|\Delta_j|)^2$ to a set of probability $\leq \gamma$. Theorem 9.4 then yields $A\log\frac{A}{4\gamma} \leq 1$ for $A = \frac{\delta(b-a)^2}{4v\gamma}$, whence $A \lesssim 1/\log(e^2/(2\gamma))$.

**Solution.** Let $0 < \delta < \gamma \leq 1/2$, $a = Q_{1-\gamma}+B$, $b = Q_{1-\delta}$, where $Q_\alpha = \inf\{z : \mathbb{P}\{f(X) \leq z\} \geq \alpha\}$ and $B = \max_{x,i}|f(x)-f(x^{(i)})|$. If $b \leq a$ then $Q_{1-\delta}-Q_{1-\gamma} \leq B$ trivially; assume $b > a$. Since $Q_{1-\delta}-Q_{1-\gamma} = (b-a)+B$, it suffices to bound $b-a$.

Define the truncation $g_{a,b}(x) = \max(a,\min(b,f(x)))$, nondecreasing and $1$-Lipschitz in $f(x)$. Then $\mathrm{Var}(g_{a,b}) \geq \mathbb{P}\{f(X) \geq b\}(b-a)^2/4 \geq \delta(b-a)^2/4$, since $\mathbb{P}\{f \geq Q_{1-\delta}\} \geq \delta$ and $\mathbb{P}\{g_{a,b}=a\} \geq 1/2$.

*Localization via the $B$-shift.* For $\phi(s)=\max(a,\min(b,s))$, $(\phi(s)-\phi(t))_- \leq (s-t)_-$. If $f(x) \leq a-B = Q_{1-\gamma}$, then $f(x^{(i)}) \leq f(x)+B \leq a$ for all $i$, so $g_{a,b}(x) = g_{a,b}(x^{(i)}) = a$. Hence $(g_{a,b}(x)-g_{a,b}(x^{(i)}))_-$ is nonzero only if $f(x) > Q_{1-\gamma}$, and
$$(g_{a,b}(X)-g_{a,b}(X^{(i)}))_-^2 \leq \mathbb{1}_{\{f(X)>Q_{1-\gamma}\}}(f(X)-f(X^{(i)}))_-^2.$$
By the symmetry $(X,X^{(i)}) \stackrel{d}{=} (X^{(i)},X)$, $\mathcal{E}(g_{a,b}) = \tfrac12\sum_i\mathbb{E}[(g_{a,b}(X)-g_{a,b}(X^{(i)}))_-^2]$, so
$$\mathcal{E}(g_{a,b}) \leq \tfrac12\,\mathbb{E}\Big[\mathbb{1}_{\{f(X)>Q_{1-\gamma}\}}\sum_i(f(X)-f(X^{(i)}))_-^2\Big] \leq \tfrac{v\gamma}{2}, \tag{1}$$
using $\sum_i(f(x)-f(x^{(i)}))_-^2 \leq v$ and $\mathbb{P}\{f(X)>Q_{1-\gamma}\} \leq \gamma$.

*Martingale differences.* With $\Delta_j = \mathbb{E}[g_{a,b}(X)\mid X_1,\dots,X_j]-\mathbb{E}[g_{a,b}(X)\mid X_1,\dots,X_{j-1}]$, $\mathbb{E}|\Delta_j| \leq \mathbb{E}|g_{a,b}(X)-g_{a,b}(X^{(j)})| = 2\mathbb{E}[(g_{a,b}(X)-g_{a,b}(X^{(j)}))_-]$ (by symmetry). Localizing as above and using Cauchy–Schwarz,
$$\mathbb{E}|\Delta_j| \leq 2\sqrt{\mathbb{E}[(g_{a,b}(X)-g_{a,b}(X^{(j)}))_-^2]}\,\sqrt{\gamma},$$
so $$\sum_j(\mathbb{E}|\Delta_j|)^2 \leq 4\gamma\sum_j\mathbb{E}[(\cdot)_-^2] = 8\gamma\,\mathcal{E}(g_{a,b}) \leq 4v\gamma^2. \tag{2}$$

*Applying Theorem 9.4.* $\mathrm{Var}(g_{a,b})\log\frac{\mathrm{Var}(g_{a,b})}{\sum_j(\mathbb{E}|\Delta_j|)^2} \leq 2\mathcal{E}(g_{a,b}) \leq v\gamma$. If $\mathrm{Var}(g_{a,b}) \leq \sum_j(\mathbb{E}|\Delta_j|)^2$, then $\delta(b-a)^2/4 \leq 4v\gamma^2$, so $b-a \leq 4\gamma\sqrt{v/\delta} \leq 4\sqrt{v\gamma/(\delta L)}$ where $L = \log\frac{e^2}{2\gamma} \geq 2$ (using $\gamma L \leq 1$ for $\gamma \in (0,1/2]$). Otherwise, with $A = \frac{\delta(b-a)^2}{4v\gamma}$: if $A < 4\gamma$ the same bound holds; if $A \geq 4\gamma$, monotonicity gives $A\log\frac{A}{4\gamma} \leq 1$.

*From $A\log\frac{A}{4\gamma} \leq 1$ to the bound.* We claim $A \leq \frac{8}{L}$. Indeed, $x \mapsto x\log\frac{x}{4\gamma}$ is increasing for $x > 4\gamma/e$, and $\frac{8}{L} > \frac{4\gamma}{e}$ since $\gamma L < 2e$ on $(0,1/2]$; if $A > 8/L$ then $1 \geq A\log\frac{A}{4\gamma} > \frac{8}{L}\log\frac{2}{\gamma L}$, but $\frac{8}{L}\log\frac{2}{\gamma L} > 1$ for $\gamma \in (0,1/2]$ (with $t=\log(1/\gamma)\geq\log2$, this is $9\log2-2+7t-8\log(2+t) > 0$, increasing in $t$ and positive at $t=\log2$). Hence $(b-a)^2 = \frac{4v\gamma A}{\delta} \leq \frac{32v\gamma}{\delta L}$.

In all cases $b-a \leq 4\sqrt{2}\sqrt{\frac{v\gamma}{\delta\log(e^2/(2\gamma))}}$, so with $K = 4\sqrt{2}$,
$$Q_{1-\delta}-Q_{1-\gamma} = (b-a)+B \leq B + K\sqrt{\frac{v\gamma}{\delta\log\frac{e^2}{2\gamma}}}. \qquad \blacksquare$$
