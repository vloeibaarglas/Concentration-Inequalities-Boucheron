**Central idea.** Adapt the truncation + Theorem 9.4 proof of Theorem 9.8 (as in Exercise 9.4) to the one-sided $(\cdot)_+$ hypothesis $\sum_i(f-f_i)_+^2 \le \phi(f)$. Truncate $f$ to $g = g_{a,b}$ with $a = Q_{1-\gamma}$, $b = Q_{1-\delta}$; since single-coordinate jumps are at most $B$, $(g-g_i)_+$ vanishes unless $Q_{1-\gamma} < f \le b+B$, so $\mathcal{E}(g)$ and the martingale differences localize to a set of probability $\le \gamma$ with $\phi$ evaluated at $b+B = Q_{1-\delta}+B$. Theorem 9.4 then yields $A\log\frac{A}{4\gamma} \le 1$ for $A \propto \frac{\delta(b-a)^2}{\gamma\phi(b+B)}$, whence the quantile gap bound. No $B$-shift of $a$ is needed (unlike the $(\cdot)_-$ case), so $b-a = Q_{1-\delta}-Q_{1-\gamma}$ directly.

**Solution.** Let $0 < \delta < \gamma \le 1/2$, $a = Q_{1-\gamma}$, $b = Q_{1-\delta}$, where $Q_\alpha = \inf\{z : \mathbb{P}\{f(X) \le z\} \ge \alpha\}$. Since $\delta < \gamma$, $a \le b$; if $a = b$ there is nothing to prove. Assume $a < b$. Put $B = \max_{x,i}|f(x)-f(x^{(i)})|$ and $L = \log\frac{e^2}{2\gamma} \ge 2$.

Define the truncation $g(x) = g_{a,b}(x) = \max(a,\min(b,f(x)))$, nondecreasing and $1$-Lipschitz in $f(x)$, so $(g(x)-g(x^{(i)}))_+ \le (f(x)-f(x^{(i)}))_+$.

*Variance lower bound.* $\mathbb{P}\{g = b\} = \mathbb{P}\{f \ge b\} \ge \delta$ and $\mathbb{P}\{g = a\} = \mathbb{P}\{f \le a\} \ge 1-\gamma \ge 1/2$. For $g \in [a,b]$,
$$\mathrm{Var}(g) \ge \mathbb{P}\{g=a\}\mathbb{P}\{g=b\}(b-a)^2 \ge \tfrac{\delta}{2}(b-a)^2, \tag{1}$$
since with $m = \mathbb{E}g = a+t(b-a)$, $\mathrm{Var}(g) \ge (m-a)^2\mathbb{P}\{g=a\}+(b-m)^2\mathbb{P}\{g=b\} = (b-a)^2[t^2q+(1-t)^2p] \ge pq(b-a)^2$ (the bracket exceeds $pq$ because $p+q \le 1$).

*Localization of the $(\cdot)_+$ sensitivity.* If $(g(x)-g(x^{(i)}))_+ > 0$ then $g(x) > a$, hence $f(x) > a = Q_{1-\gamma}$. If $f(x) > b+B$ then $f(x^{(i)}) \ge f(x)-B > b$ for every $i$, so $g \equiv b$ on $\{x\}\cup\{x^{(i)}\}$ and $(g(x)-g(x^{(i)}))_+ = 0$. Thus, with $\phi$ nondecreasing,
$$\sum_{i=1}^n (g(x)-g(x^{(i)}))_+^2 \le \mathbb{1}_{\{f(x) > Q_{1-\gamma}\}}\sum_i(f(x)-f(x^{(i)}))_+^2 \le \mathbb{1}_{\{f(x) > Q_{1-\gamma}\}}\,\phi(b+B). \tag{2}$$
By the flip symmetry $(X,X^{(i)}) \stackrel{d}{=} (X^{(i)},X)$, $\mathbb{E}[(g-g_i)_+^2] = \mathbb{E}[(g-g_i)_-^2]$, so with $\mathcal{E}(g) = \frac12\sum_i\mathbb{E}[(g-g_i)^2]$,
$$\mathcal{E}(g) = \sum_i\mathbb{E}[(g(X)-g(X^{(i)}))_+^2] \le \gamma\,\phi(b+B), \tag{3}$$
using $\mathbb{P}\{f > Q_{1-\gamma}\} \le \gamma$.

*Martingale differences.* With $\Delta_j = \mathbb{E}[g\mid X_1,\dots,X_j]-\mathbb{E}[g\mid X_1,\dots,X_{j-1}]$, $\mathbb{E}|\Delta_j| \le \mathbb{E}|g(X)-g(X^{(j)})| = 2\mathbb{E}[(g(X)-g(X^{(j)}))_+]$ by symmetry. By Cauchy–Schwarz and (2),
$$\mathbb{E}[(g-g_j)_+] \le \sqrt{\mathbb{E}[(g-g_j)_+^2]}\,\sqrt{\mathbb{P}\{f > Q_{1-\gamma}\}} \le \sqrt{\gamma}\,\sqrt{\mathbb{E}[(g-g_j)_+^2]},$$
since $(g(x)-g(x^{(j)}))_+ > 0$ implies $f(x) > Q_{1-\gamma}$. Hence
$$\sum_j(\mathbb{E}|\Delta_j|)^2 \le 4\gamma\sum_j\mathbb{E}[(g-g_j)_+^2] \le 4\gamma^2\phi(b+B). \tag{4}$$

*Applying Theorem 9.4.* Theorem 9.4 gives $\mathrm{Var}(g)\log\frac{\mathrm{Var}(g)}{\sum_j(\mathbb{E}|\Delta_j|)^2} \le 2\mathcal{E}(g)$. Write $V = \mathrm{Var}(g)$, $S = \sum_j(\mathbb{E}|\Delta_j|)^2$. If $V \le S$, then by (1) and (4), $\frac{\delta}{2}(b-a)^2 \le 4\gamma^2\phi(b+B)$, so $(b-a)^2 \le \frac{8\gamma^2\phi(b+B)}{\delta} \le \frac{8\phi(b+B)\gamma}{\delta L}$, using $\gamma L \le 1$ on $(0,1/2]$ (since $\gamma \mapsto \gamma\log\frac{e^2}{2\gamma}$ is increasing there, with value $1$ at $\gamma = 1/2$).

Otherwise $V > S$. Put $A = \frac{\delta(b-a)^2}{4\gamma\phi(b+B)}$. From $V\log(V/S) \le 2\mathcal{E}(g)$ with (1), (3), (4):
$$\frac{\delta}{2}(b-a)^2\log\!\left(\frac{\delta(b-a)^2}{8\gamma^2\phi(b+B)}\right) \le 2\gamma\phi(b+B),$$
i.e. $A\log\frac{A}{2\gamma} \le 1$. If $A < 4\gamma$ then $(b-a)^2 = \frac{4\gamma\phi(b+B)A}{\delta} < \frac{16\gamma^2\phi(b+B)}{\delta} \le \frac{16\phi(b+B)\gamma}{\delta L}$. If $A \ge 4\gamma$, monotonicity gives $A\log\frac{A}{4\gamma} \le 1$.

*From $A\log\frac{A}{4\gamma} \le 1$ to the bound.* We claim $A \le \frac{8}{L}$. If $A \le 4\gamma$ this follows from $\gamma L \le 1 < 2$. Else $x \mapsto x\log\frac{x}{4\gamma}$ is increasing for $x > 4\gamma/e$, and $\frac{8}{L} > \frac{4\gamma}{e}$ (as $\gamma L \le 1 < 2e$); if $A > 8/L$ then $1 \ge A\log\frac{A}{4\gamma} > \frac{8}{L}\log\frac{2}{\gamma L}$. But $\frac{8}{L}\log\frac{2}{\gamma L} > 1$ on $(0,1/2]$: with $u = \frac{1}{2\gamma} \ge 1$, $w = \log u \ge 0$, $L = 2+w$, this is $\frac{8}{2+w}(\log 4 + w - \log(2+w)) = 8(1-\frac{2-\log4+\log s}{s}) \ge 8(1-0.654) > 2.7$ for $s = 2+w \ge 2$ (the fraction $\frac{0.614+\log s}{s}$ decreases on $[2,\infty)$). Contradiction. Hence $A \le 8/L$ and
$$(b-a)^2 = \frac{4\gamma\phi(b+B)A}{\delta} \le \frac{32\,\phi(b+B)\,\gamma}{\delta\,L}.$$

In all cases $b-a \le 4\sqrt{2}\sqrt{\frac{\phi(b+B)\gamma}{\delta\log(e^2/(2\gamma))}}$. Since $b-a = Q_{1-\delta}-Q_{1-\gamma}$ and $b+B = Q_{1-\delta}+B$, with $K = 4\sqrt{2}$,
$$Q_{1-\delta}-Q_{1-\gamma} \le K\sqrt{\frac{\phi(Q_{1-\delta}+B)\,\gamma}{\delta\,\log\frac{e^2}{2\gamma}}}, \qquad 0 < \delta < \gamma \le \tfrac12.$$

*In particular.* With $a_k = Q_{1-2^{-k}}$, take $\delta = 2^{-(k+1)}$, $\gamma = 2^{-k}$: then $\gamma/\delta = 2$ and $L = \log(e^2 2^{k-1}) = 2+(k-1)\log2 \ge k\log2$, so
$$a_{k+1}-a_k \le K\sqrt{\frac{2}{\log2}}\sqrt{\frac{\phi(a_{k+1}+B)}{k}},$$
and absorbing $\sqrt{2/\log2}$ into $K$ gives $a_{k+1}-a_k \le K\sqrt{\phi(a_{k+1}+B)/k}$. ∎
