**Central idea.** The $n$-dimensional inequality tensorizes from a two-point ($n=1$) inequality: condition on all but one coordinate, apply the 1D bound, and iterate, using Jensen twice (convexity of $(\cdot)_+$ for the gradient, convexity of the Euclidean norm to recombine). The 1D inequality for $a \ge b$ with $K = \kappa(p) = (1-p)/(1+p)$ is proved by squaring and factoring the difference as $\frac{p^2(p-1)(a-b)^2}{1+p}\,Q$ with an explicitly nonnegative $Q$. Monotonicity lets one use $\kappa(p)$ instead of $\max(\kappa(p),\kappa(1-p))$, and for $f = \mathbf{1}_A$ the $\alpha(f)^2$ term vanishes.

**Solution.** Write $\alpha(x) = x(1-x)$, $\kappa(p) = \frac{1-p}{1+p}$.

*1D lemma.* For $0 \le b \le a \le 1$ and $K = \kappa(p)$,
$$p\sqrt{\alpha(a)^2+K(a-b)^2} + (1-p)\alpha(b) \ge \alpha(pa+(1-p)b). \tag{1}$$
Let $m = pa+(1-p)b$. By concavity, $\alpha(m)-(1-p)\alpha(b) \ge p\alpha(a) \ge 0$, so with both sides nonnegative it suffices to square:
$$[\alpha(m)-(1-p)\alpha(b)]^2 - p^2\alpha(a)^2 - p^2K(a-b)^2 \le 0.$$
A direct expansion with $K = \frac{1-p}{1+p}$ gives the factorization
$$[\alpha(m)-(1-p)\alpha(b)]^2 - p^2\alpha(a)^2 - p^2K(a-b)^2 = \frac{p^2(p-1)(a-b)^2}{1+p}\,Q,$$
where $Q = (1-p^2)b(2a-b) + [(1+p)a-1]^2$. Since $\frac{p^2(p-1)(a-b)^2}{1+p} \le 0$, it suffices that $Q \ge 0$. If $b(2a-b) \ge 0$ this is clear. Else $b > 2a \ge 0$ (hence $a < 1/2$), and
$$(1-(1+p)a)^2 - (1-p^2)(1-2a) = [p-(1+p)a]^2 \ge 0,$$
so $Q \ge (1-p^2)[b(2a-b)+(1-2a)]$. Since $0 < b-2a$ and $b \le 1$, $b(b-2a) \le b-2a$, giving $b(2a-b)+(1-2a) \ge 1-b \ge 0$. Hence $Q \ge 0$, proving (1).

*Tensorization.* We prove the first claim by induction on $n$ with $K = \max(\kappa(p),\kappa(1-p))$. For $n = 1$, write $a = f(1)$, $b = f(-1)$; if $a \ge b$ the claim follows from (1) since $K \ge \kappa(p)$, and if $b > a$ it follows by swapping the roles of $\pm1$ (which swaps $p \leftrightarrow 1-p$ and leaves $K$ invariant). Let $n \ge 2$, $x = (x',x_n)$, and $g(x') = \mathbb{E}_{X_n}[f(x',X_n)]$. By the induction hypothesis,
$$\alpha(\mathbb{E}f) = \alpha(\mathbb{E}_{X'}g) \le \mathbb{E}_{X'}\!\left[\sqrt{\alpha(g)^2+K\|\nabla^+g\|^2}\right].$$
For fixed $x'$, (1) applied to $a = f(x',1)$, $b = f(x',-1)$ gives $\alpha(g(x')) \le \mathbb{E}_{X_n}[h]$ with $h = \sqrt{\alpha(f)^2+K(\nabla^+_n f)^2}$. For $i < n$, Jensen gives $\nabla^+_i g(x') \le \mathbb{E}_{X_n}[\nabla^+_i f(x',X_n)]$. Hence, with $w_i = \nabla^+_i f$,
$$\alpha(g)^2+K\|\nabla^+g\|^2 \le (\mathbb{E}_{X_n}h)^2 + K\sum_{i<n}(\mathbb{E}_{X_n}w_i)^2,$$
and by convexity of the Euclidean norm,
$$\sqrt{\alpha(g)^2+K\|\nabla^+g\|^2} \le \mathbb{E}_{X_n}\!\left[\sqrt{h^2+K\sum_{i<n}w_i^2}\right] = \mathbb{E}_{X_n}\!\left[\sqrt{\alpha(f)^2+K\|\nabla^+f\|^2}\right].$$
Taking $\mathbb{E}_{X'}$ and using Fubini completes the induction.

If $f$ is increasing, so is $g$ (expectation preserves order), and each slice satisfies $f(x',1) \ge f(x',-1)$; running the same induction with $K = \kappa(p)$ throughout gives the second claim.

For a monotone set $A$, apply the second claim to $f = \mathbf{1}_A$. Since $\alpha(\mathbf{1}_A) \equiv 0$,
$$P(A)(1-P(A)) = \alpha(\mathbb{E}f) \le \sqrt{\kappa(p)}\,\mathbb{E}\|\nabla^+\mathbf{1}_A\|,$$
i.e. $\mathbb{E}\|\nabla^+\mathbf{1}_A\| \ge \sqrt{\frac{1+p}{1-p}}\,P(A)(1-P(A))$.

*Tightness.* The inequality is not tight for any of the three. For a dictatorship $A = \{x_1 = 1\}$: $\mathbb{E}\|\nabla^+\mathbf{1}_A\| = p$ while the right side is $p\sqrt{1-p^2}$, ratio $1/\sqrt{1-p^2} > 1$. For a singleton $A = \{(1,\dots,1)\}$: $\mathbb{E}\|\nabla^+\mathbf{1}_A\| = p^n\sqrt{n}$, ratio $\sqrt{\frac{n(1-p)}{1+p}}/(1-p^n) \to \infty$ as $n \to \infty$. For majority $A = \{\sum x_i > 0\}$ ($n = 2m+1$, $p = 1/2$): $\mathbb{E}\|\nabla^+\mathbf{1}_A\| = \binom{2m+1}{m+1}2^{-(2m+1)}\sqrt{m+1} \to 1/\sqrt{\pi}$ while the right side is $\sqrt{3}/4$, ratio $\to 4/\sqrt{3\pi} \approx 1.30 > 1$. ∎
