**Central idea.** Apply the Efron–Stein inequality (Theorem 3.1) with the leave-one-out supremum $Z_i = \sup_{s}\sum_{j\ne i}\alpha_{j,s}Y_j$. From $\sup A - \sup B \le \sup(A-B)$ we get $|Z-Z_i| \le \sup_s|\alpha_{i,s}Y_i| \le |Y_i|$ pointwise (no maximizers needed); since $|\alpha|\le1$, $(Z-Z_i)^2 \le Y_i^2$, whence $\mathrm{Var}(Z) \le n\sigma^2$. As $\mathbb{E}Z \ge 0$, the stated $n\sigma^2+2\mathbb{E}Z$ follows. This is the variance estimate underlying Bousquet's inequality, where $n\sigma^2+2\mathbb{E}Z$ is the natural variance proxy.

**Solution.** Assume $\mathcal{T}$ is countable (so suprema are measurable; the general separable case follows by approximation) and nonempty. Write $S_s = \sum_{i=1}^n\alpha_{i,s}Y_i$, so $Z = \sup_{s\in\mathcal{T}}S_s$. The Bernstein moment condition gives $\mathbb{E}Y_i^2 \le \sigma^2$ (case $q=2$) and exponential tails, so $Z$ is integrable with $\mathbb{E}Z^2 \le n\sum_i\mathbb{E}Y_i^2 < \infty$; moreover $\mathbb{E}Z \ge \sup_s\mathbb{E}S_s = 0$ since each $Y_i$ is centered.

For $i=1,\dots,n$ let $Z_i = \sup_{s\in\mathcal{T}}\sum_{j\ne i}\alpha_{j,s}Y_j$, which is $\sigma(Y^{(i)})$-measurable for $Y^{(i)}=(Y_j)_{j\ne i}$. By the Efron–Stein inequality (Theorem 3.1), in the form $\mathrm{Var}(Z) \le \inf_{Z_i}\sum_i\mathbb{E}(Z-Z_i)^2$,
$$\mathrm{Var}(Z) \le \sum_{i=1}^n \mathbb{E}\big[(Z-Z_i)^2\big].$$

For each $s$, $Z_i \ge \sum_{j\ne i}\alpha_{j,s}Y_j$, so
$$Z - Z_i = \sup_{s}\sum_{j}\alpha_{j,s}Y_j - Z_i \le \sup_{s}\Big(\sum_{j}\alpha_{j,s}Y_j - \sum_{j\ne i}\alpha_{j,s}Y_j\Big) = \sup_{s}\alpha_{i,s}Y_i \le |Y_i|.$$
Applying the same with $Z$ and $Z_i$ exchanged, $Z_i - Z \le \sup_{s}(-\alpha_{i,s}Y_i) \le |Y_i|$. Hence $|Z - Z_i| \le |Y_i|$ pointwise (no maximizers needed), and
$$\mathbb{E}\big[(Z-Z_i)^2\big] \le \mathbb{E}[Y_i^2] \le \sigma^2.$$

Summing over $i$ gives $\mathrm{Var}(Z) \le n\sigma^2$. Since $\mathbb{E}Z \ge 0$, we obtain $\mathrm{Var}(Z) \le n\sigma^2 + 2\mathbb{E}Z$. ∎
