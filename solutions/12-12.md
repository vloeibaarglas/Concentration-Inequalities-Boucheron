**Central idea.** The nonzero eigenvalues of the Gram matrix $G$ coincide with those of $S = \sum_i X_iX_i^T$. By the Ky Fan variational principle, $Z = \sum_{j=1}^k \mu_j(S) = \max_P \mathrm{tr}(PS)$ over rank-$k$ orthogonal projectors. With $P^*$ the maximizer, $0 \le Z - Z^{(i)} \le \|P^*X_i\|^2 \le M^2$ and $\sum_i(Z-Z^{(i)}) \le \mathrm{tr}(P^*S) = Z$. So $Z/M^2$ is self-bounding, and Exercise 12.11 (Theorem 6.12) gives the mgf bound $(\mathbb{E}Z/M^2)\phi(M^2\lambda)$. Its Chernoff transform is the Bennett tail $\exp(-\frac{\mathbb{E}Z}{M^2}h(\frac{t}{\mathbb{E}Z}))$.

**Solution.** Write $G = XX^T$ where $X$ is the $n \times d$ matrix with rows $X_i^T$. Then $G$ is PSD with eigenvalues $\lambda_1 \ge \cdots \ge \lambda_n \ge 0$. Its nonzero eigenvalues coincide with the nonzero eigenvalues of the $d \times d$ matrix $S := X^TX = \sum_{i=1}^n X_iX_i^T$ (a standard fact: $XX^T$ and $X^TX$ have the same nonzero eigenvalues). Let $\mu_1 \ge \cdots \ge \mu_d \ge 0$ be the eigenvalues of $S$. At most $d$ eigenvalues of $G$ are nonzero and zeros sort last, so $\lambda_j = \mu_j$ for $j \le d$. As $k \le d$,
$$Z = \sum_{j=1}^k \lambda_j = \sum_{j=1}^k \mu_j(S).$$
By the Courant–Fisher (Ky Fan) variational characterization,
$$Z = \max\{\mathrm{tr}(PS) : P \text{ an orthogonal projector of rank } k\} = \max_P \sum_{i=1}^n \mathrm{tr}(PX_iX_i^T).$$
The maximum is attained because the set of rank-$k$ projectors is compact.

Let $M := \mathrm{ess\,sup}\|X_1\| < \infty$ (the $X_i$ are i.i.d. and a.s. bounded). If $M = 0$ then $Z\equiv0$ and there is nothing to prove, so assume $M>0$. For each $i$, let $S^{(i)} = S - X_iX_i^T$ and $Z^{(i)} = \sum_{j=1}^k \mu_j(S^{(i)}) = \max_P \mathrm{tr}(PS^{(i)})$, a function of $(X_j)_{j\ne i}$. Since $\mathrm{tr}(PX_iX_i^T) = \|PX_i\|^2 \ge 0$ for every $P$, we have $\mathrm{tr}(PS) \ge \mathrm{tr}(PS^{(i)})$ for each $P$, hence $Z \ge Z^{(i)}$. Let $P^*$ attain the maximum for $S$. Then
$$Z - Z^{(i)} = \mathrm{tr}(P^*S) - \max_P \mathrm{tr}(PS^{(i)}) \le \mathrm{tr}(P^*S) - \mathrm{tr}(P^*S^{(i)}) = \|P^*X_i\|^2 \le \|X_i\|^2 \le M^2 \quad \text{a.s.}$$
Summing over $i$ with the same $P^*$,
$$\sum_{i=1}^n (Z - Z^{(i)}) \le \sum_{i=1}^n \mathrm{tr}(P^*X_iX_i^T) = \mathrm{tr}(P^*S) = Z.$$
Thus $W := Z/M^2$ satisfies $0 \le W - W^{(i)} \le 1$ and $\sum_i(W - W^{(i)}) \le W$, so $W$ is self-bounding. Applying Exercise 12.11 (i.e. Theorem 6.12) to $W$ and rescaling as there gives
$$\mathrm{Var}(Z) \le M^2\,\mathbb{E}Z, \qquad \log\mathbb{E}e^{\lambda(Z-\mathbb{E}Z)} \le \frac{\mathbb{E}Z}{M^2}\,\phi(M^2\lambda) \quad \forall\,\lambda \in \mathbb{R},$$
with $\phi(u) = e^u - u - 1$.

*Bennett-type tails.* Write $a = M^2$, $m = \mathbb{E}Z$ (assume $m>0$; if $m = 0$ then $Z = 0$ a.s. since $Z\ge0$), and $h(x) = (1+x)\log(1+x) - x$ for $x\ge-1$. For $t>0$ and $\lambda>0$, Markov's inequality gives $\mathbb{P}\{Z\ge m+t\}\le\exp(-\lambda t + (m/a)\phi(a\lambda))$. Substituting $u = a\lambda$, so that $\lambda t = (m/a)\,u\,(t/m)$,
$$\sup_{\lambda>0}\Big[\lambda t - \frac ma\phi(a\lambda)\Big] = \frac ma\sup_{u>0}\Big[u\frac tm - \phi(u)\Big] = \frac ma\,h\Big(\frac tm\Big),$$
where the last step is the standard identity $\sup_{u>0}[ux - \phi(u)] = h(x)$ for $x>0$, attained at $u = \log(1+x)$. Hence
$$\mathbb{P}\{Z \ge \mathbb{E}Z + t\} \le \exp\!\left(-\frac{\mathbb{E}Z}{M^2}\,h\!\left(\frac{t}{\mathbb{E}Z}\right)\right),\qquad t>0.$$
Using $h(x)\ge\frac{x^2}{2(1+x/3)}$ for $x\ge0$ gives the Bernstein form
$$\mathbb{P}\{Z \ge \mathbb{E}Z + t\} \le \exp\!\left(-\frac{t^2}{2M^2(\mathbb{E}Z + t/3)}\right).$$
For the lower tail, apply the mgf bound with $\lambda<0$. Since $\phi(u)\le u^2/2$ for $u\le0$, for $0<t\le\mathbb{E}Z$ we get
$$\mathbb{P}\{Z\le\mathbb{E}Z - t\}\le\exp\!\left(-\frac{\mathbb{E}Z}{M^2}h\!\left(-\frac t{\mathbb{E}Z}\right)\right)\le\exp\!\left(-\frac{t^2}{2M^2\,\mathbb{E}Z}\right).$$
(Here $h(-x)\ge x^2/2$ for $x\in[0,1]$, and the lower tail is trivially $0$ for $t>\mathbb{E}Z$ since $Z\ge0$.) These are Bennett-like concentration inequalities for the sum of the top $k$ eigenvalues.

*Correction note.* An earlier version of this solution displayed the upper tail as $\exp(-\frac{\mathbb{E}Z}{M^2}h(\frac{M^2t}{\mathbb{E}Z}))$, with an extra factor $M^2$ inside $h$. That does not follow from the mgf bound and is false. Take $d = k = 1$ and $X_i = 2\,\mathrm{Bern}(0.1)$ with $n = 100$, so $Z = \sum_iX_i^2 = 4\,\mathrm{Bin}(100,0.1)$, $M^2 = 4$ and $\mathbb{E}Z = 40$. At $t = 20$ the true probability is $\mathbb{P}\{Z\ge60\} = \mathbb{P}\{\mathrm{Bin}(100,0.1)\ge15\}\approx0.0726$. The wrong display gives $e^{-10h(2)}\approx2.36\cdot10^{-6}$, which is below the true probability, so it is not a valid upper bound. The correct bound gives $e^{-10h(1/2)}\approx0.339$, and the Bernstein form gives $\approx0.343$. (Numbers checked in Python.)
