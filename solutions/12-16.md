**Central idea.** Truncate each coordinate at $\tau_n$: $X_{i,s} = V_{i,s} + W_{i,s}$ with $|V_{i,s}| \le \tau_n$ bounded and $W_{i,s}$ the heavy tail. Then $Z \le Z_1 + Z_2$, and symmetry gives $\mathbb{E}Z \ge \mathbb{E}Z_1 - \mathbb{E}Z_2$. The bounded part $Z_1$ is controlled by Exercise 12.15 (Bousquet's inequality, Theorem 12.5) after scaling by $\tau_n$, using $\mathrm{Var}(V_{i,s}) \le 8\sigma^2 + 32c^2$; the tail part $Z_2$ is controlled by Exercise 12.14 via $Z_2 \le \sum_i Y_i\mathbf{1}_{\{Y_i \ge \tau_n\}}$. A union-bound split of $\{Z \ge (1+\eta)\mathbb{E}Z + t\}$ into $\{Z_1 \ge \cdots\}$ and $\{Z_2 \ge \varepsilon t\}$ yields the three-term bound.

**Solution.** Write $X_{i,s} = V_{i,s} + W_{i,s}$ with $V_{i,s} = X_{i,s}\mathbf{1}_{\{|X_{i,s}|<\tau_n\}}$ and $W_{i,s} = X_{i,s}\mathbf{1}_{\{|X_{i,s}|\ge\tau_n\}}$. Since $|X_{i,s}|$ is invariant under the sign flip $X_{i,s} \mapsto -X_{i,s}$, both $V_{i,s}$ and $W_{i,s}$ are symmetric, hence centered. Also $Z = \sup_s\sum_i X_{i,s} \le \sup_s\sum_i V_{i,s} + \sup_s\sum_i W_{i,s} = Z_1 + Z_2$.

*Check 1: $\mathbb{E}Z \ge \mathbb{E}Z_1 - \mathbb{E}Z_2$.* Since $V_{i,s} = X_{i,s} - W_{i,s}$,
$$\sup_s\sum_i V_{i,s} \le \sup_s\sum_i X_{i,s} + \sup_s\sum_i(-W_{i,s}) = Z + \sup_s\sum_i(-W_{i,s}).$$
By symmetry $-W_{i,s} \stackrel{d}{=} W_{i,s}$, so $\sup_s\sum_i(-W_{i,s}) \stackrel{d}{=} Z_2$. Taking expectations, $\mathbb{E}Z_1 \le \mathbb{E}Z + \mathbb{E}Z_2$.

*Check 2: $\mathbb{E}Z_2 \le \tau_n(1+1/\log n)$.* Since $|W_{i,s}| \le Y_i\mathbf{1}_{\{Y_i\ge\tau_n\}}$,
$$Z_2 \le \sum_{i=1}^n \sup_s|W_{i,s}| \le \sum_{i=1}^n Y_i\mathbf{1}_{\{Y_i\ge\tau_n\}},$$
so $\mathbb{E}Z_2 \le n\,\mathbb{E}[Y_1\mathbf{1}_{\{Y_1\ge\tau_n\}}]$. By the layer-cake identity and the sub-gamma tail bound $\mathbb{P}\{Y_1 \ge \sqrt{2\sigma^2u}+cu\} \le e^{-u}$,
\begin{align*}
\mathbb{E}[Y_1\mathbf{1}_{\{Y_1\ge\tau_n\}}] &= \tau_n\mathbb{P}\{Y_1\ge\tau_n\} + \int_{\tau_n}^{\infty}\mathbb{P}\{Y_1\ge t\}\,dt \\
&\le \frac{\tau_n}{n} + \int_{\log n}^{\infty}e^{-u}\Big(\sqrt{\tfrac{\sigma^2}{2u}}+c\Big)\,du \qquad (t = \sqrt{2\sigma^2u}+cu) \\
&\le \frac{1}{n}\Big(\tau_n + \sqrt{\tfrac{\sigma^2}{2\log n}} + c\Big),
\end{align*}
using $\tau_n = \sqrt{2\sigma^2\log n}+c\log n$ (i.e. $u=\log n$) and $\int_{\log n}^{\infty}u^{-1/2}e^{-u}du \le (\log n)^{-1/2}/n$. Hence
$$\mathbb{E}Z_2 \le \tau_n + c + \sqrt{\tfrac{\sigma^2}{2\log n}} \le \tau_n + c + \sqrt{\tfrac{2\sigma^2}{\log n}} = \tau_n\Big(1+\tfrac{1}{\log n}\Big).$$

*Check 3: $\mathbb{P}\{Z_2 \ge t\} \le 2\exp(-t/(8\tau_n))$.* From $Z_2 \le \sum_i Y_i\mathbf{1}_{\{Y_i\ge\tau_n\}}$, Chernoff's bound applied to this nonnegative sum — exactly the proof of 12.14's tail, which uses only the envelope mgf — gives $\mathbb{P}\{Z_2 \ge t\} \le \mathbb{P}\{\sum_i Y_i\mathbf{1}_{\{Y_i\ge\tau_n\}} \ge t\} \le 2\exp(-t/(4\tau_n)) \le 2\exp(-t/(8\tau_n))$.

*Check 4: the decomposition.* From $Z \le Z_1+Z_2$ and $\mathbb{E}Z \ge \mathbb{E}Z_1-\mathbb{E}Z_2$,
$$\{Z \ge (1+\eta)\mathbb{E}Z+t\} \subseteq \{Z_1+Z_2 \ge (1+\eta)\mathbb{E}Z_1-(1+\eta)\mathbb{E}Z_2+t\}.$$
For any $\varepsilon>0$, $\{Z_1+Z_2 \ge A+t\} \subseteq \{Z_1 \ge A+(1-\varepsilon)t\}\cup\{Z_2 \ge \varepsilon t\}$ (contrapositive: $Z_1 < A+(1-\varepsilon)t$ and $Z_2 < \varepsilon t$ imply $Z_1+Z_2 < A+t$). With $A = (1+\eta)\mathbb{E}Z_1-(1+\eta)\mathbb{E}Z_2$,
$$\mathbb{P}\{Z \ge (1+\eta)\mathbb{E}Z+t\} \le \mathbb{P}\{Z_1 \ge (1+\eta)\mathbb{E}Z_1-(1+\eta)\mathbb{E}Z_2+(1-\varepsilon)t\} + \mathbb{P}\{Z_2 \ge \varepsilon t\}.$$

*Main bound.* Apply Exercise 12.15 to $Z_1$. The summands $V_{i,s}$ satisfy $|V_{i,s}| \le \tau_n$ and, by Theorem 2.3, $\mathrm{Var}(V_{i,s}) \le \mathbb{E}[V_{i,s}^2] \le \mathbb{E}[X_{i,s}^2] = \mathrm{Var}(X_{i,s}) \le 8\sigma^2+32c^2$. Scaling by $\tau_n$, $V_{i,s}/\tau_n$ are bounded by $1$ with variance factor $8n(\sigma^2+4c^2)/\tau_n^2$. Exercise 12.15 (with $\kappa = 2/\eta+1/3$) gives, for deviation $(1-2\varepsilon)t$ (the $-(1+\eta)\mathbb{E}Z_2$ term being absorbed into the passage from $(1-\varepsilon)$ to $(1-2\varepsilon)$),
$$\mathbb{P}\{Z_1 \ge (1+\eta)\mathbb{E}Z_1+(1-2\varepsilon)t\} \le \exp\!\Big(-\frac{(1-2\varepsilon)^2t^2}{16(1+\delta)n(\sigma^2+4c^2)}\Big) + \exp\!\Big(-\frac{\delta(1-2\varepsilon)t}{2(1+\delta)\kappa\tau_n}\Big).$$
Indeed, with $u = (1-2\varepsilon)t/\tau_n$ in 12.15: the Gaussian exponent is $\frac{u^2}{2(1+\delta)\cdot 8n(\sigma^2+4c^2)/\tau_n^2} = \frac{(1-2\varepsilon)^2t^2}{16(1+\delta)n(\sigma^2+4c^2)}$, and the exponential exponent is $\frac{\delta u}{2(1+\delta)\kappa} = \frac{\delta(1-2\varepsilon)t}{2(1+\delta)\kappa\tau_n}$. Combining with Check 3 for $\mathbb{P}\{Z_2 \ge \varepsilon t\} \le 2\exp(-\varepsilon t/(8\tau_n))$ yields
$$\mathbb{P}\{Z \ge (1+\eta)\mathbb{E}Z+t\} \le \exp\!\Big(-\frac{(1-2\varepsilon)^2t^2}{16(1+\delta)n(\sigma^2+4c^2)}\Big) + \exp\!\Big(-\frac{\delta(1-2\varepsilon)t}{2(1+\delta)\kappa\tau_n}\Big) + 2\exp\!\Big(-\frac{\varepsilon t}{8\tau_n}\Big).$$
The last term is trivial (exceeds $1$) when $\varepsilon t \le 4\tau_n$, since then $\varepsilon t/(8\tau_n) \le 1/2$ and $2e^{-1/2} > 1$. (The passage from $(1-\varepsilon)t-(1+\eta)\mathbb{E}Z_2$ to $(1-2\varepsilon)t$ above needs $\varepsilon t \ge (1+\eta)\mathbb{E}Z_2$; otherwise $\varepsilon t < (1+\eta)\mathbb{E}Z_2 \le (1+\eta)(1+1/\log n)\tau_n \le 4\tau_n$ for $\eta\le1$, $n\ge3$, so the third term already exceeds $1$ and the bound holds trivially.) ∎
