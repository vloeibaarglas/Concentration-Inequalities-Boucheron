**Central idea.** Haussler's probabilistic method: if $A_1,\dots,A_N$ are $\delta$-separated in $L_2(Q)$, then $n\asymp(\log N)/\delta^2$ random samples from $Q$ distinguish all $N$ traces with positive probability, so $\log N$ is bounded by the VC-entropy $V\log(en/V)$ (Sauer). Unwinding the implicit inequality $L\le V\log(4eL/(V\delta^2))$ for $L=\log N$ gives an explicit bound — but the $V$ in the denominator inside the logarithm as stated makes the claimed inequality false.

**Status: repaired.** The bound as originally stated is false — counterexample: $\mathcal{X}=[10]$, $\mathcal{A}=2^{[10]}$ (VC-dimension $V=10$), $Q$ uniform, $\delta=1$, $\kappa=2$: then $\emptyset$ and $[10]$ satisfy $\|1_\emptyset-1_{[10]}\|_{L_2(Q)}^2=1$, so $H(1,\mathcal{A})\ge\log2>0$, while the stated bound gives $20\log(0.4)<0$. The $V$ in the denominator of $\frac{2\kappa}{V\delta^2}$ is a typo; the argument below proves the corrected bound $H(\delta,\mathcal{A})\le\frac{\kappa}{\kappa-1}V\log\left(\frac{4e\kappa}{\delta^2}\right)$ for all $\kappa>1$, which is sound.

**Solution.** (of the corrected bound) Let $H(\delta,\mathcal{A})=\sup_Q\log N(\delta,\mathcal{A},L_2(Q))$ be the universal entropy, $N(\delta,\cdot)$ the covering number. If $\delta>1$ then no two distinct sets are $\delta$-separated (as $\|1_{A_i}-1_{A_j}\|_{L_2(Q)}^2=Q(A_i\triangle A_j)\le1<\delta^2$), so $H(\delta,\mathcal{A})=0$ and there is nothing to prove; assume $\delta\le1$. A maximal $\delta$-separated set is a $\delta$-cover, so it suffices to bound $\log N$ for $N$ $\delta$-separated sets $A_1,\dots,A_N$. If $N=1$ there is nothing to prove; assume $N\ge2$ (hence $V\ge1$, as two distinct sets shatter the singleton $\{x\}$ for any $x\in A_1\triangle A_j$).

Fix $Q$ and let $A_1,\dots,A_N\in\mathcal{A}$ be $\delta$-separated: $Q(A_i\triangle A_j)=\|1_{A_i}-1_{A_j}\|_{L_2(Q)}^2\ge\delta^2$ for $i\ne j$. Put $n=\big\lfloor4\log N/\delta^2\big\rfloor\ge2$ and draw $X_1,\dots,X_n$ i.i.d.\ $\sim Q$, $S=\{X_1,\dots,X_n\}$. For fixed $i\ne j$,
$$\mathbb{P}\{A_i\cap S=A_j\cap S\}=(1-Q(A_i\triangle A_j))^n\le(1-\delta^2)^n\le e^{-n\delta^2}\le\frac{e^{\delta^2}}{N^4}\le\frac{e}{N^4},$$
since $n\ge4\log N/\delta^2-1$. By the union bound over $\binom N2$ pairs,
$$\mathbb{P}\{\text{all }A_i\cap S\text{ distinct}\}\ge1-\binom N2\frac{e}{N^4}\ge1-\frac{e}{2N^2}>0\qquad(N\ge2).$$
Hence some realization has $|\{A\cap S:A\in\mathcal{A}\}|\ge N$. If $n\ge V$, Sauer's lemma gives $|\{A\cap S\}|\le(en/V)^V$, so with $n\le4\log N/\delta^2$,
$$\log N\le V\log(en/V)\le V\log\left(\frac{4e\log N}{V\delta^2}\right).\tag{*}$$
Put $L=\log N$ and $t=L/V$, so $t\le\log(4et/\delta^2)=\log(4e/\delta^2)+\log t$. Fix $\kappa>1$. If $t\le1$ then $L\le V\le\frac{\kappa}{\kappa-1}V\log(4e\kappa/\delta^2)$ since $\frac{\kappa}{\kappa-1}>1$ and $\log(4e\kappa/\delta^2)>1$ (as $\delta\le1$, $\kappa>1$). If $t>1$, use $\log t\le t/\kappa+\log\kappa-1$:
$$t\le\log(4e/\delta^2)+t/\kappa+\log\kappa-1,\quad\text{so}\quad t\left(1-\frac1\kappa\right)\le\log(4e\kappa/\delta^2),$$
giving $t\le\frac{\kappa}{\kappa-1}\log(4e\kappa/\delta^2)$, i.e. $L\le\frac{\kappa}{\kappa-1}V\log(4e\kappa/\delta^2)$. If $n<V$ then $4L/\delta^2<V+1$ (as $n=\lfloor4L/\delta^2\rfloor$), so $L<(V+1)\delta^2/4\le(V+1)/4\le V\le\frac{\kappa}{\kappa-1}V\log(4e\kappa/\delta^2)$ as above (using $V\ge1$). Thus in all cases $\log N\le\frac{\kappa}{\kappa-1}V\log(4e\kappa/\delta^2)$, and taking $\sup_Q$ gives $H(\delta,\mathcal{A})\le\frac{\kappa}{\kappa-1}V\log(4e\kappa/\delta^2)$ for all $\kappa>1$. ∎
