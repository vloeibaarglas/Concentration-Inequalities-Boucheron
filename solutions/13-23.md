**Central idea.** The case $p = 2$ is an identity: independence and $\mathbb{E}X_i = 0$ give $\mathbb{E}\|S_n\|_2^2 = \sum_i \mathbb{E}\|X_i\|_2^2$. The $\ell_p$-norm comparison inequalities $\|x\|_q \le \|x\|_p \le d^{1/p-1/q}\|x\|_q$ for $1 \le p \le q \le \infty$ then transfer this to general $p$, producing $K(p,d) = d^{2/p-1}$ for $p \le 2$ and $d^{1-2/p}$ for $p \ge 2$. (This crude dimension-dependent bound is what the sharper Nemirovski inequality, Theorem 13.10, improves upon.)

**Solution.** Let $X_1, \ldots, X_n$ be independent mean-zero random vectors in $\mathbb{R}^d$ and $S_n = \sum_{i=1}^n X_i$. For $p = 2$, expanding coordinatewise and using independence with $\mathbb{E}X_i = 0$,
$$\mathbb{E}\|S_n\|_2^2 = \sum_{j=1}^d \mathbb{E}\left(\sum_{i=1}^n X_{i,j}\right)^2 = \sum_{j=1}^d \sum_{i=1}^n \mathbb{E}X_{i,j}^2 = \sum_{i=1}^n \mathbb{E}\|X_i\|_2^2,$$
since $\mathbb{E}[X_{i,j}X_{k,j}] = \mathbb{E}X_{i,j}\,\mathbb{E}X_{k,j} = 0$ for $i \ne k$.

Recall the norm comparisons on $\mathbb{R}^d$: for $1 \le p \le q \le \infty$,
$$\|x\|_q \le \|x\|_p \le d^{1/p - 1/q}\,\|x\|_q,$$
by Hölder's inequality (power-mean monotonicity).

*Case $1 \le p \le 2$.* From $\|S_n\|_p \le d^{1/p-1/2}\|S_n\|_2$,
$$\mathbb{E}\|S_n\|_p^2 \le d^{2/p-1}\,\mathbb{E}\|S_n\|_2^2 = d^{2/p-1}\sum_{i=1}^n \mathbb{E}\|X_i\|_2^2 \le d^{2/p-1}\sum_{i=1}^n \mathbb{E}\|X_i\|_p^2 = d^{2/p-1}V,$$
using $\|X_i\|_2 \le \|X_i\|_p$ for $p \le 2$.

*Case $2 \le p \le \infty$.* From $\|S_n\|_p \le \|S_n\|_2$,
$$\mathbb{E}\|S_n\|_p^2 \le \mathbb{E}\|S_n\|_2^2 = \sum_{i=1}^n \mathbb{E}\|X_i\|_2^2 \le d^{1-2/p}\sum_{i=1}^n \mathbb{E}\|X_i\|_p^2 = d^{1-2/p}V,$$
using $\|X_i\|_2 \le d^{1/2-1/p}\|X_i\|_p$ for $p \ge 2$ (with the convention $1/\infty = 0$).

Thus $\mathbb{E}\|S_n\|_p^2 \le K(p,d)V$ with $K(p,d) = d^{2/p-1}$ for $1 \le p \le 2$ and $K(p,d) = d^{1-2/p}$ for $2 \le p \le \infty$, noting both formulas give $K(2,d) = 1$. ∎
