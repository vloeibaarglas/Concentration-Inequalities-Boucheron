**Central idea.** Poissonize with i.i.d. $Y_i \sim \mathrm{Poisson}(1)$ independent of the $X_i$: the constant $1-1/e$ is exactly $\mathbb{E}[Y_i \wedge 1] = \mathbb{P}\{Y_i \ge 1\}$. Move the $Y$-expectation outside the supremum (Jensen, since $\sup_s \mathbb{E}[\cdot] \le \mathbb{E}[\sup_s \cdot]$), then condition on the $Y$'s: the active index set has size $K \le \sum_{i=1}^n Y_i \sim \mathrm{Poisson}(n)$, and $k \mapsto \mathbb{E}\sup_s \sum_{i=1}^k X_{i,s}$ is nondecreasing by centeredness, so the thinned sum is dominated by the Poissonized sum.

**Solution.** Let $Y_1, \ldots, Y_n$ be i.i.d. $\mathrm{Poisson}(1)$, independent of the $X_i$. Since $Y_i \wedge 1 = \mathbf{1}_{\{Y_i \ge 1\}}$,
$$c := \mathbb{E}[Y_i \wedge 1] = \mathbb{P}\{Y_i \ge 1\} = 1 - e^{-1} = 1 - \frac1e.$$
Hence, with $c > 0$ pulled inside the supremum,
$$\left(1-\frac1e\right)\mathbb{E}\sup_{s\in\mathcal{T}}\sum_{i=1}^n X_{i,s} = \mathbb{E}_X\!\left[\sup_{s\in\mathcal{T}} \sum_{i=1}^n \mathbb{E}_Y[Y_i \wedge 1]\, X_{i,s}\right].$$
For fixed values $x_{i,s}$ of the $X_{i,s}$, Jensen's inequality for the convex supremum gives
$$\sup_{s\in\mathcal{T}} \mathbb{E}_Y\!\left[\sum_{i=1}^n (Y_i \wedge 1) x_{i,s}\right] \le \mathbb{E}_Y\!\left[\sup_{s\in\mathcal{T}} \sum_{i=1}^n (Y_i \wedge 1) x_{i,s}\right].$$
Taking $\mathbb{E}_X$ yields
$$\left(1-\frac1e\right)\mathbb{E}\sup_{s\in\mathcal{T}}\sum_{i=1}^n X_{i,s} \le \mathbb{E}\sup_{s\in\mathcal{T}} \sum_{i=1}^n (Y_i \wedge 1) X_{i,s}. \tag{*}$$
Write $(Y_i \wedge 1) = \mathbf{1}_{\{Y_i \ge 1\}}$ and condition on $\mathbf{Y} = (Y_1,\ldots,Y_n)$. Let $K = \sum_{i=1}^n \mathbf{1}_{\{Y_i \ge 1\}}$. Given $\mathbf{Y}$, the set $\{i : Y_i \ge 1\}$ is fixed with cardinality $K$, and since the $X_i$ are i.i.d. and independent of $\mathbf{Y}$,
$$\mathbb{E}\!\left[\sup_{s\in\mathcal{T}} \sum_{i=1}^n \mathbf{1}_{\{Y_i \ge 1\}} X_{i,s} \,\middle|\, \mathbf{Y}\right] = \phi(K), \quad \text{where } \phi(k) := \mathbb{E}\sup_{s\in\mathcal{T}} \sum_{i=1}^k X_{i,s}.$$
The map $\phi$ is nondecreasing: for $a_s = \sum_{i=1}^k X_{i,s}$ fixed,
$$\mathbb{E}_{X_{k+1}}\!\left[\sup_{s\in\mathcal{T}} (a_s + X_{k+1,s})\right] \ge \sup_{s\in\mathcal{T}} \big(a_s + \mathbb{E}X_{k+1,s}\big) = \sup_{s\in\mathcal{T}} a_s,$$
by Jensen and $\mathbb{E}X_{k+1,s} = 0$ (centeredness). Since $\mathbf{1}_{\{Y_i \ge 1\}} \le Y_i$,
$$K \le M := \sum_{i=1}^n Y_i,$$
and $M \sim \mathrm{Poisson}(n)$ is independent of the $X_i$. Thus, from $(*)$,
$$\mathbb{E}\sup_{s\in\mathcal{T}} \sum_{i=1}^n (Y_i \wedge 1) X_{i,s} = \mathbb{E}[\phi(K)] \le \mathbb{E}[\phi(M)] = \mathbb{E}\sup_{s\in\mathcal{T}} \sum_{i=1}^{M} X_{i,s} = \mathbb{E}\sup_{s\in\mathcal{T}} \sum_{i=1}^{N_n} X_{i,s},$$
identifying $M \stackrel{d}{=} N_n$. ($\mathcal{T}$ finite, so all suprema are maxima.) ∎
