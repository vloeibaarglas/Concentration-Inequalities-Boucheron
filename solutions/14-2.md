**Central idea.** All six are the convexity of $(u,v)\mapsto\Phi''(u)v^2$ in disguise: $A^{\Phi}$ and $B^{\Phi}$ are averages of $C^{\Phi}$ along lines $(u+tv,v)$ (giving i)$\iff$iii)$\iff$ii) by integration and a $h\to0$ scaling limit), the Hessian of $C^{\Phi}$ gives v), $(-1/\Phi'')''$ computes to the same inequality (giving iv)$\iff$v)), and the Jensen gap $J_t$ is a convex combination of $A^{\Phi}$-terms (giving i)$\iff$vi)). $\Phi$ is assumed $C^4$ on an open interval.

**Solution.** Write $C(u,v)=\Phi''(u)v^2$. Its Hessian is
$$\nabla^2C=\begin{pmatrix}\Phi''''(u)v^2&2\Phi'''(u)v\\2\Phi'''(u)v&2\Phi''(u)\end{pmatrix}.$$
Hence (for $C^2$ $C$) iii) holds iff this is PSD everywhere, i.e. $\Phi''(u)\ge0$, $\Phi''''(u)\ge0$ and $\det=2v^2(\Phi''(u)\Phi''''(u)-2\Phi'''(u)^2)\ge0$ for all $u,v$.

iii)$\iff$v): If $C$ is convex and $\Phi''\equiv0$, $\Phi$ is affine. Otherwise $\Phi''(u_0)>0$ for some $u_0$; let $J$ be the maximal open interval about $u_0$ with $\Phi''>0$. On $J$, $\psi:=-1/\Phi''$ satisfies $\psi''=(\Phi''\Phi''''-2\Phi'''^2)/(\Phi'')^3\ge0$ (by $\det\ge0$), so $\psi$ is convex on $J$. If $J$ were not the whole domain it would have a finite endpoint $u_1$ with $\Phi''(u_1)=0$, whence $\psi\to-\infty$ there — impossible for a convex function (tangent lower bound at any interior point). Thus $\Phi''>0$ everywhere and $\Phi''\Phi''''\ge2\Phi'''^2$, i.e. v). Conversely, if $\Phi$ is affine, $C\equiv0$ is convex; if $\Phi''>0$ and $\Phi''\Phi''''\ge2\Phi'''^2$, then $\Phi''''\ge2\Phi'''^2/\Phi''\ge0$, so $\nabla^2C$ has nonnegative diagonal and determinant, hence is PSD and $C$ is convex.

iv)$\iff$v): If $\Phi$ is affine both hold. Else $\Phi''>0$ and $(-1/\Phi'')''=(\Phi''\Phi''''-2\Phi'''^2)/(\Phi'')^3$; since $(\Phi'')^3>0$, $-1/\Phi''$ is convex iff $\Phi''\Phi''''\ge2\Phi'''^2$.

i)$\iff$iii): $A^{\Phi}(u,v)=\Phi(u+v)-\Phi(u)-\Phi'(u)v=\int_0^1(1-t)\Phi''(u+tv)v^2dt=\int_0^1(1-t)C(u+tv,v)dt$ (Taylor with integral remainder). If $C$ is convex, $(u,v)\mapsto C(u+tv,v)$ is convex for each $t$ (linear precomposition), and $A^{\Phi}$, an integral thereof against $(1-t)\ge0$, is convex. Conversely, $(u,v)\mapsto A^{\Phi}(u,hv)/h^2$ is convex and tends to $\frac12\Phi''(u)v^2=\frac12C(u,v)$ as $h\to0$; a pointwise limit of convex functions is convex.

ii)$\iff$iii): $B^{\Phi}(u,v)=(\Phi'(u+v)-\Phi'(u))v=\int_0^1\Phi''(u+tv)v^2dt=\int_0^1C(u+tv,v)dt$, so iii)$\Rightarrow$ii) as above; and $B^{\Phi}(u,hv)/h^2\to\Phi''(u)v^2=C(u,v)$, giving ii)$\Rightarrow$iii).

i)$\iff$vi): Put $J_t(a,b)=t\Phi(a)+(1-t)\Phi(b)-\Phi(ta+(1-t)b)$ and $u=ta+(1-t)b$. Since $t(a-u)+(1-t)(b-u)=0$,
$$J_t(a,b)=t\,A^{\Phi}(u,(1-t)(a-b))+(1-t)\,A^{\Phi}(u,-t(a-b)),$$
so i)$\Rightarrow$vi) (convexity preserved under linear precomposition and positive combinations; $J_0=J_1\equiv0$). Conversely, $J_t(a,b)/t\to\Phi(a)-\Phi(b)-\Phi'(b)(a-b)=A^{\Phi}(b,a-b)$ as $t\to0^+$; if each $J_t$ is convex so is the limit, and $(a,b)\mapsto(b,a-b)$ is a linear isomorphism, giving i). ∎
