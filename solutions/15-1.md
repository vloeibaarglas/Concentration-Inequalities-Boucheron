**Central idea.** Extend $x_q$ to a smooth function $X(t)$ for real $t \geq 4$ and show $X'(t) \geq 0$ by bounding the logarithmic derivative $X'/X = a(t) - \frac{Cw(t)}{1+Cw(t)}b(t)$ with explicit elementary Taylor bounds; since $\lim_{t \to \infty} X(t) = 1$, monotonicity forces $x_q \leq 1$ for all integers $q \geq 4$.

**Solution.** Recall $K = 1/(e-\sqrt{e})$ (p. 444), so with $C := 1/K = e-\sqrt{e}$,
$$x_q = \left(\frac{q-1}{q}\right)^{q/2}\left(1 + C\left(\frac{q-2}{q-1}\right)^{(q-2)/2}\right), \qquad q \geq 4.$$
For real $t \geq 4$ define
$$X(t) = \left(1-\frac1t\right)^{t/2}\left[1 + C\left(1-\frac1{t-1}\right)^{(t-2)/2}\right],$$
so $X(q) = x_q$ for integer $q \geq 4$. Write $X(t) = e^{u(t)}(1+Ce^{v(t)})$ with
$$u(t) = \tfrac{t}{2}\log\left(1-\tfrac1t\right), \qquad v(t) = \tfrac{t-2}{2}\log\left(1-\tfrac1{t-1}\right).$$
Then, with $w(t) = e^{v(t)}$,
$$\frac{X'(t)}{X(t)} = u'(t) + \frac{Cw(t)}{1+Cw(t)}v'(t) = a(t) - \frac{Cw(t)}{1+Cw(t)}b(t),$$
where
$$a(t) = \tfrac12\log\left(1-\tfrac1t\right)+\tfrac1{2(t-1)}, \qquad b(t) = -\tfrac12\log\left(1-\tfrac1{t-1}\right)-\tfrac1{2(t-1)},$$
using $u'(t) = \frac12\log(1-\frac1t)+\frac1{2(t-1)}$ and $v'(t) = \frac12\log(1-\frac1{t-1})+\frac1{2(t-1)} = -b(t)$.
Since $\log(1-x) < -x$ for $x \in (0,1)$, $v'(t) < 0$, so $w$ is decreasing and $w(t) \leq w(4) = 2/3$ for $t \geq 4$; hence, $s \mapsto Cs/(1+Cs)$ being increasing,
$$\frac{Cw(t)}{1+Cw(t)} \leq \frac{\frac23C}{1+\frac23C}.$$
Now $\frac{\frac23C}{1+\frac23C} \leq \frac7{12} \iff C \leq \frac{21}{10}$, which holds since $C = e-\sqrt{e} < 2.8-1.5 < 2.1$ (using $e < 2.8$ and $e > 2.25$).

We bound $a$ from below and $b$ from above. For $x \in (0,\frac13]$, $\log(1+x) \leq x-\frac{x^2}{2}+\frac{x^3}{3}$ (alternating Taylor series with decreasing terms), so with $x = \frac1{t-1}$,
$$\log\left(1-\tfrac1t\right) = -\log\left(1+\tfrac1{t-1}\right) \geq -\tfrac1{t-1}+\tfrac1{2(t-1)^2}-\tfrac1{3(t-1)^3},$$
giving $a(t) \geq \frac1{4(t-1)^2}-\frac1{6(t-1)^3} = \frac1{(t-1)^2}\left(\frac14-\frac1{6(t-1)}\right) \geq \frac7{36(t-1)^2}$ for $t \geq 4$.
For $b$, write $y = \frac1{t-1} \in (0,\frac13]$; then $-\log(1-y)-y = \sum_{k\geq2}y^k/k \leq \frac{y^2}{2}+\frac{y^3}{2} \leq \frac{2y^2}{3}$ (since $\sum_{k\geq3}y^k/k \leq \frac{y^3}{3(1-y)} \leq \frac{y^3}{2}$), so $b(t) \leq \frac1{3(t-1)^2}$.

Consequently $\frac{a(t)}{b(t)} \geq \frac{7/36}{1/3} = \frac7{12} \geq \frac{Cw(t)}{1+Cw(t)}$, whence $\frac{X'(t)}{X(t)} \geq 0$ for all $t \geq 4$; i.e., $X$ is nondecreasing.

Finally,
$$\lim_{q\to\infty}\left(1-\tfrac1q\right)^{q/2} = e^{-1/2}, \qquad \lim_{q\to\infty}\left(1-\tfrac1{q-1}\right)^{(q-2)/2} = e^{-1/2},$$
since $\frac{q-2}{2(q-1)} \to \frac12$. Hence
$$\lim_{q\to\infty} x_q = e^{-1/2}\left(1+Ce^{-1/2}\right) = e^{-1/2} + (e-\sqrt{e})e^{-1} = 1.$$
As $X$ is nondecreasing with limit $1$, $X(t) \leq 1$ for all $t \geq 4$; in particular $x_q = X(q) \leq 1$ for every integer $q \geq 4$. ∎
